<lore>
Das Emzuli-Transportrohr bietet dir mehrere Extraktionsfilter – du musst nur in einem Gatter einen davon auswählen, damit das Rohr diesen Filter verwendet.
</lore>
<no_lore>
„Extraktionseinstellung“ ist eine Gatteraktion, die jedes Gatter bietet, das auf einem Emzuli-Transportrohr platziert ist.
</no_lore>

<chapter name="Voraussetzungen"/>
Wenn die Aktion aktiviert ist, erlaubt das Gatter dem Emzuli-Rohr, Gegenstände in der Farbe der gewählten Extraktionseinstellung zu extrahieren.
Ohne eine vom Gatter festgelegte Extraktionseinstellung kann das Emzuli-Rohr keine Gegenstände extrahieren.
