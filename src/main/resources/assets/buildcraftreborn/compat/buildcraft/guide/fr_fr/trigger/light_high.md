<lore>
Fait-il clair devant la porte ? Si oui, le modificateur se déclenche.
</lore>
<no_lore>
« Clair » est un modificateur de porte disponible sur toute porte placée sur un tuyau auquel est aussi fixé un Détecteur de lumière de cette couleur.
</no_lore>

<chapter name="Conditions"/>
Lorsqu'il est sélectionné, les actions connectées ne s'activent que si le niveau de lumière du bloc situé devant le Détecteur de lumière est élevé.
