経路マーカーは、「建築」がたどる経路を示します。
</no_lore>
<chapter name="経路の作り方"/>
経路を通したい場所に、64ブロック以内の間隔で経路マーカーを設置します。マーカーコネクターを持っている間は、つなげられるマーカー同士がうっすらとしたレーザーで示されます。そのレーザーを見て右クリックすると、その2つのマーカーがつながります。マーカーをつなげていけば、もっと長い経路を作れます。
<recipes_usages stack="buildcraftreborn:marker_path"/>
経路マーカーを右クリックすると、経路の向きが反転します。「建築」は経路を始点から終点へとたどります。
<link to="buildcraftreborn:item/marker_connector"/>
<chapter name="経路の使い方"/>
経路上のマーカーに接するように、マーカーが背後に来る向きで「建築」を設置します。「建築」は経路を取り込み、マーカーはアイテムとしてドロップします。そして、ブループリントやテンプレートを一度だけでなく、経路に沿って1歩ごとに建てていきます。
