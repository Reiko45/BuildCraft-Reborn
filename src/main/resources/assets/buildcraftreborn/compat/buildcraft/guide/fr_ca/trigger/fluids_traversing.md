</lore>
<no_lore>
« Fluides en Transit » est un modificateur de porte disponible sur toute porte placée sur un tuyau étanche.
</no_lore>

<chapter name="Conditions"/>
Lorsqu'il est sélectionné, les actions connectées ne s'activent que si du fluide circule dans le tuyau.
