</no_lore>

<chapter name="Krav"/>
Når handlingen er aktivert, aktiveres den tilkoblede rørkabelen i samme farge.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Parameter"/>
Når Rørsignal på brukes og den installerte porten har parametere, blir Rørsignal på og Rørsignal av for de andre tilkoblede rørkabelfargene tilgjengelige som parametere.
Velger du Rørsignal på som parameter for den opprinnelige utløseren din, kan du aktivere flere rørkabler når de opprinnelige utløserne aktiveres.
