<no_lore>
프로그래밍 테이블은 레이저 동력으로 레드스톤 보드를 프로그래밍합니다.
</no_lore>
<chapter name="사용법"/>
왼쪽 위 슬롯에 빈 레드스톤 보드를 넣으세요. 보드에 넣을 수 있는 모든 프로그램이 가운데에 표시됩니다. 하나를 클릭해 선택하세요(다시 클릭하면 선택 해제). 그러면 레이저가 테이블에 동력을 공급하고, 동력이 충분히 모이면 프로그래밍된 보드가 왼쪽 아래 슬롯에 나타납니다. 테이블은 선택한 프로그램을 유지하므로, 출력 슬롯이 비면 같은 보드를 다시 만듭니다.
