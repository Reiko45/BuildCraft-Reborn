<lore>
Quando há itens passando pelo tubo, o gatilho é ativado.
</lore>
<no_lore>
Itens Atravessando é um gatilho de porta lógica disponível em qualquer porta lógica colocada em um tubo de transporte.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações conectadas só são ativadas quando há um item passando pelo tubo.

<chapter name="Parâmetros"/>
Ao usar Itens Atravessando em uma porta lógica com parâmetros disponíveis, o espaço de Filtro ao lado dele fica disponível como parâmetro.
Colocar um item no espaço de filtro permite verificar se o item selecionado está passando pelo tubo antes de acionar o gatilho.
