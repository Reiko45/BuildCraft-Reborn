<lore>
Wusstest du, dass du einen angeschlossenen Rohrpulsar nur ein einziges Mal pulsen lassen kannst?
</lore>
<no_lore>
„Einzelner Energiepuls“ ist eine Gatteraktion, die jedes Gatter bietet, an dessen Rohr auch ein Rohrpulsar angebracht ist.
</no_lore>

<chapter name="Voraussetzungen"/>
Wenn die Aktion aktiviert ist, wird der Rohrpulsar kurz eingeschaltet und das Rohr erhält genug Energie für einen einzigen Arbeitsvorgang.

<link to="buildcraftreborn:item/plug_pulsar"/> 

<chapter name="Richtungen"/>
Gatter können die Aktion „Energiepulsar“ mehrmals in verschiedenen Farben anzeigen – eine für jeden angeschlossenen Rohrpulsar.
Die Farbe der Aktion zeigt, auf welcher Seite des Rohrs der Rohrpulsar sitzt, damit du die Rohrpulsare auseinanderhalten kannst.
