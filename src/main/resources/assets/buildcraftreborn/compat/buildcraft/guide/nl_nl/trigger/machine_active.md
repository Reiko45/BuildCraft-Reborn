<lore>
Heeft de machine ernaast echt werk dat ze zou kunnen doen?
</lore>
<no_lore>
‘Heeft werk’ is een poorttrigger die beschikbaar is op elke poort die naast een machine is geplaatst die kan werken.
</no_lore>

<chapter name="Vereisten"/>
Als deze trigger is gekozen, worden de verbonden acties alleen geactiveerd als de aangrenzende machine werk heeft dat ze zou kunnen doen.

Let op: niet alle machines ondersteunen de trigger ‘Heeft werk’.
