<lore>
Неужели у соседней машины больше совсем нет работы?
</lore>
<no_lore>
«Работа завершена» — триггер, доступный в любом гейте, установленном рядом с машиной, которая завершила свою работу.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда соседняя машина выполнила всю работу, какая у неё была.

Примечание: не все машины поддерживают триггер «Работа завершена».
