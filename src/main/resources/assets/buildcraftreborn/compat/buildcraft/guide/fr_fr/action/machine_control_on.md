<lore>
Cette action met la machine en marche.
</lore>
<no_lore>
« Marche » est une action de porte disponible sur toute porte placée à côté d'une machine susceptible de fonctionner.
</no_lore>

<chapter name="Conditions"/>
Lorsque l'action est activée, la machine se met à fonctionner.
Remarque : toutes les machines ne prennent pas en charge l'action « Marche ».

<chapter name="Orientation des modificateurs"/>
Une porte peut afficher l'action « Marche » plusieurs fois, dans des couleurs différentes, une pour chacune des machines connectées.
La couleur de l'action indique la direction de la machine par rapport au tuyau, ce qui vous permet de distinguer les machines entre elles.
