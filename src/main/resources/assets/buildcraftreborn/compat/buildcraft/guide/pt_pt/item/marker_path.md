<lore>
Uma estrada não se constrói sozinha, mas um Construtor com um caminho para seguir anda lá perto.
</lore>
<no_lore>
O Marcador de Caminhos marca um caminho para um Construtor seguir.
</no_lore>
<chapter name="Criar um caminho"/>
Coloca Marcadores de Caminhos por onde o caminho deve passar, até 64 blocos de distância uns dos outros. Enquanto seguras um Conector de marcadores, lasers ténues mostram que marcadores podem ser ligados: olha para um e clica com o botão direito para ligar esses dois marcadores. Continua a ligar marcadores para fazer um caminho mais longo.
<recipes_usages stack="buildcraftreborn:marker_path"/>
Clica com o botão direito num Marcador de Caminhos para inverter o sentido do caminho: um Construtor segue o caminho do início até ao fim.
<link to="buildcraftreborn:item/marker_connector"/>
<chapter name="Usar um caminho"/>
Coloca um Construtor encostado a um marcador do caminho, com o marcador atrás dele. O Construtor fica com o caminho, os marcadores caem como itens e ele constrói o seu diagrama ou modelo em cada passo ao longo do caminho, em vez de o construir uma só vez.
