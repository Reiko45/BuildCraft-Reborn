<lore>
Každý robot začíná jako prázdná deska.
</lore>
<no_lore>
Programátorský stůl programuje ruditové desky laserovou energií.
</no_lore>
<chapter name="Použití"/>
Vlož prázdnou ruditovou desku do slotu vlevo nahoře. Uprostřed se zobrazí všechny programy, které deska může přijmout: kliknutím jeden vyber (dalším kliknutím výběr zrušíš). Stůl pak napájejí lasery, a jakmile dostane dost energie, objeví se naprogramovaná deska ve slotu vlevo dole. Stůl si zvolený program pamatuje, takže jakmile se výstupní slot vyprázdní, vyrobí další stejnou desku.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Trubky mohou desky vkládat a naprogramované desky odebírat.
