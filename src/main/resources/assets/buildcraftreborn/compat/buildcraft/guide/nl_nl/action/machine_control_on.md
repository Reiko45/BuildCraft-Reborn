<lore>
Hiermee zet je de machine aan.
</lore>
<no_lore>
‘Aan’ is een poortactie die beschikbaar is op elke poort die naast een machine is geplaatst die kan werken.
</no_lore>

<chapter name="Vereisten"/>
Wanneer de actie is geactiveerd, begint de machine te werken.
Let op: niet alle machines ondersteunen de actie ‘Aan’.

<chapter name="Triggerrichtingen"/>
Poorten kunnen de actie ‘Aan’ meerdere keren in verschillende kleuren tonen, één voor elke aangesloten machine.
De kleur van de actie toont in welke richting de machine ten opzichte van de pijp ligt, zodat je de machines van elkaar kunt onderscheiden.
