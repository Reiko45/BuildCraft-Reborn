A máquina ao lado já não tem mesmo mais trabalho nenhum para fazer?
</lore>
<no_lore>
Trabalho Concluído é um gatilho de gate disponível em qualquer gate colocado junto a uma máquina que tenha concluído a sua operação.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações ligadas só são ativadas quando a máquina adjacente concluiu todo o trabalho que poderia fazer.

Nota: nem todas as máquinas suportam o gatilho Trabalho Concluído.
