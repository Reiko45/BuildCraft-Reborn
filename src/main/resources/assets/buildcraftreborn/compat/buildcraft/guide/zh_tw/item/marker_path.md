<lore>
道路不會自己蓋好，但一台有路徑可循的建築工也差不多了。
</lore>
<no_lore>
路徑標誌能標出一條路徑，供建築工依循。
</no_lore>
<chapter name="建立路徑"/>
在路徑要經過的地方放置路徑標誌，彼此最多相距 64 格。手持標誌連接器時，微弱的雷射會顯示哪些標誌可以相連：看著其中一個並按右鍵，即可連接這兩個標誌。持續連接更多標誌，就能形成更長的路徑。
<recipes_usages stack="buildcraftreborn:marker_path"/>
對路徑標誌按右鍵可反轉路徑的方向：建築工會從路徑的起點一路依循到終點。
<link to="buildcraftreborn:item/marker_connector"/>
<chapter name="使用路徑"/>
將建築工緊貼路徑上的某個標誌放置，並讓標誌位於它的後方。建築工會接收這條路徑，標誌會掉落成物品，接著建築工會沿著路徑在每一步都建造它的藍圖或樣板，而不是只建造一次。
