La Porte d'écluse est une machine qui fonctionne sans énergie : les fluides qu'on y achemine par tuyau sont déversés vers le bas, dans le monde.
<recipes_usages stack="buildcraftreborn:flood_gate"/>
La porte d'écluse place les fluides dans un rayon de 64 blocs, du bas vers le haut et du centre vers l'extérieur.
