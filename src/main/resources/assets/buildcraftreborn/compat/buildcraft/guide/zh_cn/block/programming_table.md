</lore>
<no_lore>
编程台利用激光能量为红石板编程。
</no_lore>
<chapter name="用法"/>
把一块空白红石板放入左上角的槽位。中间会显示这块板可以写入的所有程序：点击其中一个即可选中（再点一次取消选中）。随后由镭射器为编程台供能，能量足够后，编程完成的红石板会出现在左下角的槽位中。编程台会保持所选程序，所以输出槽一空，它就会再制作一块同样的红石板。
<recipes_usages stack="buildcraftreborn:programming_table"/>
管道可以输入红石板，也可以取出编程好的红石板。
