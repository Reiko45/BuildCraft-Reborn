<lore>
Dans quelle direction le tuyau doit-il travailler ou transporter ? Vers l'est ? Choisissez simplement cette action.
</lore>
<no_lore>
« Orienter vers le côté Est » est une action de porte disponible sur toute porte placée sur un tuyau qui a besoin d'une direction pour fonctionner, lorsque l'est est une direction valide.
</no_lore>

<chapter name="Définir la direction"/>
Lorsque l'action est activée, le tuyau sur lequel la porte est placée prend l'est comme direction.
Le tuyau envoie donc son contenu vers l'est, ou effectue ses opérations dans le monde de son côté est.
