<lore>
Para onde você quer que o tubo trabalhe ou transporte? Para o oeste? É só selecionar esta ação.
</lore>
<no_lore>
Apontar para o Lado Oeste é uma ação de porta lógica disponível em qualquer porta lógica colocada em um tubo que precise de uma direção definida para funcionar, desde que o oeste seja uma direção válida.
</no_lore>

<chapter name="Definindo a direção"/>
Quando a ação é ativada, o tubo em que ela está colocada define o Oeste como sua direção.
Isso significa que o tubo enviará seu conteúdo para o oeste ou realizará suas operações no mundo pelo seu lado oeste.
