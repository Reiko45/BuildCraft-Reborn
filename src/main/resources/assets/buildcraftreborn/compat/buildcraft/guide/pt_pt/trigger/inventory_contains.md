<no_lore>
Itens no Inventário é um gatilho de gate disponível em qualquer gate que tenha um inventário colocado ao lado.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações ligadas só são ativadas quando o inventário ligado tem itens lá dentro.

<chapter name="Parâmetros"/>
Com Itens no Inventário, se o gate instalado tiver parâmetros disponíveis, os espaços de filtro ao lado ficam disponíveis como parâmetro.
Colocar itens nos espaços de filtro permite-te verificar, antes de acionar, se o inventário tem algum dos itens selecionados nos espaços de filtro.

<chapter name="Direções do gatilho"/>
Os gates podem mostrar o gatilho Itens no Inventário várias vezes, em cores diferentes, para representar cada um dos inventários ligados.
A cor do gatilho representa a direção do inventário em relação ao tubo, para que possas distinguir cada inventário.
