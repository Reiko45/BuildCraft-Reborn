<lore>
Avec autant de blocs et d'objets, 9 emplacements, ce n'est pas très pratique pour aiguiller toutes les possibilités d'objets dans des tuyaux en diamant.
</lore>
<no_lore>
La Liste permet d'étendre les possibilités de filtrage de vos objets.
</no_lore>
<chapter name="Informations"/>
Pour ouvrir l'interface de la Liste, tenez-la en main et faites un clic droit. Vous pouvez ensuite nommer votre Liste en haut, puis placer les objets à filtrer dans les emplacements pour créer des objets fantômes.
<recipes_usages stack="buildcraftreborn:list"/>

<chapter name="Boutons"/>
Placez simplement l'objet de référence dans l'emplacement le plus à gauche, puis choisissez le bouton qui convient.

Devoir récupérer et insérer chaque variante d'un objet que vous voulez filtrer peut être fastidieux ; c'est pourquoi la Liste propose différents modes :
Correspondance exacte : l'objet doit être identique à celui inséré, par exemple avoir la même usure et les mêmes enchantements.
Type : les objets identiques, mais faits d'un autre matériau. Par exemple, pour un engrenage de fer, ce mode accepte n'importe quel engrenage, comme un engrenage de bois, un engrenage de pierre, etc.
Matériau : les objets faits exactement du même matériau. Par exemple, pour un engrenage de fer, ce mode accepte tout ce qui est fait directement de fer : blocs de fer, lingots, minerai ou pépites.

Malheureusement, tous les objets du jeu ne sont pas pris en charge.
