<chapter name="Rörets funktion"/>
Vätskor kan inte färdas genom röret, eftersom alla vätskor som når mitten förstörs automatiskt.

Vissa maskiner kan mata ut vätskor direkt i ett vätskerör av tomhet utan att de behöver gå via ett extraheringsrör.

<no_detail>
Vätskerör har en intern vätsketank som rymmer 1 hink per sida och 1 hink i mitten.
</no_detail>
