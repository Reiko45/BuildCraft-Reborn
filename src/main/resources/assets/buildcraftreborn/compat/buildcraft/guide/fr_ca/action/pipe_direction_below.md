<lore>
Dans quelle direction le tuyau doit-il travailler ou transporter ? Vers le bas ? Choisissez simplement cette action.
</lore>
<no_lore>
« Orienter vers le côté Bas » est une action de porte disponible sur toute porte placée sur un tuyau qui a besoin d'une direction pour fonctionner, lorsque le bas est une direction valide.
</no_lore>

<chapter name="Définir la direction"/>
Lorsque l'action est activée, le tuyau sur lequel la porte est placée prend le bas comme direction.
Le tuyau envoie donc son contenu vers le bas, ou effectue ses opérations dans le monde vers le bas.
