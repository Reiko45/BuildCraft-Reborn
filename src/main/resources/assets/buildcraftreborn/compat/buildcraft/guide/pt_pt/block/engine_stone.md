<lore>
Depois de experimentares o que se pode fazer com um simples motor de redstone, descobres uma forma de queimar combustíveis de fornalha para produzir uma quantidade decente de energia, a um ritmo de 1MJ/t.
</lore>
<no_lore>
O Motor a Vapor é um motor mais potente que usa combustíveis de fornalha para gerar MJ. Produz uma quantidade constante de energia de 1 MJ/t.
</no_lore>
<chapter name="Informação"/>
Os Motores a Vapor são tão eficientes como uma fornalha normal no que toca à produção de energia.
<recipes_usages stack="buildcraftreborn:engine_stone"/>
<chapter name="Funcionamento do motor"/>
Os motores do BuildCraft têm 5 fases de temperatura, que determinam a velocidade a que o motor trabalha: Azul, Verde, Amarelo, Vermelho e Preto.
Os Motores a Vapor só ficam pretos se a reserva interna de energia do motor encher por a energia não ter para onde ir; nesse caso, o motor sobreaquece e é preciso usar a Chave Inglesa nele para o arrefecer.
Os motores ligam-se sempre ao consumidor de MJ compatível mais próximo.
Podes usar uma Chave Inglesa para o rodar e mudar o bloco que está a alimentar.
Os Motores a Vapor podem ser «encadeados» em linha, até um total de 3 motores.
Como todos os motores, <bold>precisa de um sinal de redstone para funcionar.</bold>
Podes usar gates para detetar as fases de temperatura dos motores e assim controlá-los melhor.
