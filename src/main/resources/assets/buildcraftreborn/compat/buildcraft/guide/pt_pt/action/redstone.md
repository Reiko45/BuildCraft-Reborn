<lore>
Quando acionada, emite um sinal de redstone.
</lore>
<no_lore>
Sinal de Redstone é uma ação de gate disponível em qualquer gate colocado.
</no_lore>

<chapter name="Requisitos"/>
Quando a ação é ativada, emite um sinal de redstone.

<chapter name="Parâmetros"/>
Com Sinal de Redstone, se o gate instalado tiver parâmetros disponíveis, Gate Apenas Lateral fica disponível como parâmetro.
Selecionar Gate Apenas Lateral faz com que o sinal de redstone seja emitido apenas pelo lado onde o gate está colocado.
