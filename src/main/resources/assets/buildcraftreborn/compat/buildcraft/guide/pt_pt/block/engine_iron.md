<lore>

</lore>
<no_lore>
O Motor de Combustão é o motor mais potente do BuildCraft e consegue usar combustíveis para produzir energia.
</no_lore>
<chapter name="Informação"/>
Para aproveitares estes fluidos combustíveis, tens de os enviar por tubos para o motor, juntamente com um refrigerante que impeça o sobreaquecimento.
<recipes_usages stack="buildcraftreborn:engine_iron"/>
<chapter name="Combustíveis diferentes"/>
Cada fluido combustível produz uma quantidade diferente de energia durante um tempo diferente, consoante o combustível usado.

Usar combustíveis sujos num motor faz com que fique entupido de resíduo, que terás de extrair.

<chapter name="Funcionamento do motor"/>
Os motores do BuildCraft têm 5 fases de temperatura, que determinam a velocidade a que o motor trabalha: Azul, Verde, Amarelo, Vermelho e Preto.
Os Motores de Combustão só ficam pretos se a reserva interna de energia do motor encher por a energia não ter para onde ir; nesse caso, o motor sobreaquece e é preciso usar a Chave Inglesa nele para o arrefecer.
Os motores ligam-se sempre ao consumidor de MJ compatível mais próximo.
Podes usar uma Chave Inglesa para o rodar e mudar o bloco que está a alimentar.

Os Motores de Combustão podem ser «encadeados» em linha, até um total de 5 motores.

Como todos os motores, <bold>precisa de um sinal de redstone para funcionar.</bold>
Podes usar gates para detetar as fases de temperatura dos motores e assim controlá-los melhor.
