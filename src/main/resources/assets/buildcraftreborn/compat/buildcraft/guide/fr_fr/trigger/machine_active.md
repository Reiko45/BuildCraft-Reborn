<lore>
La machine voisine a-t-elle vraiment du travail à faire ?
</lore>
<no_lore>
« Tâches en cours » est un modificateur de porte disponible sur toute porte placée à côté d'une machine susceptible de fonctionner.
</no_lore>

<chapter name="Conditions"/>
Lorsqu'il est sélectionné, les actions connectées ne s'activent que si la machine adjacente a du travail à faire.

Remarque : toutes les machines ne prennent pas en charge le modificateur « Tâches en cours ».
