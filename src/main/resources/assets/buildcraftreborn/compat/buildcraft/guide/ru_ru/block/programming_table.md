<no_lore>
Стол программирования программирует красные платы с помощью лазерной энергии.
</no_lore>
<chapter name="Использование"/>
Положите пустую красную плату в левую верхнюю ячейку. В середине показаны все программы, которые можно записать на эту плату: щёлкните по программе, чтобы выбрать её (и ещё раз, чтобы отменить выбор). Затем лазеры снабжают стол энергией, и, когда её накопится достаточно, запрограммированная плата появится в левой нижней ячейке. Стол запоминает выбранную программу, поэтому, как только ячейка выдачи освободится, он изготовит такую же плату снова.

Трубы могут подавать в стол платы и забирать запрограммированные.
