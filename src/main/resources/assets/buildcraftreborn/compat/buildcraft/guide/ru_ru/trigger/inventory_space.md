<lore>
Есть ли в соседнем сундуке место для новых предметов?
</lore>
<no_lore>
«В инвентаре есть место» — триггер, доступный в любом гейте, рядом с которым находится инвентарь.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в подключённом инвентаре есть пустые ячейки, куда можно положить предметы.

<chapter name="Параметры"/>
Если выбран триггер «В инвентаре есть место» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны соседние ячейки фильтра.
Если положить предметы в ячейки фильтра, триггер сработает, только если в инвентаре есть пустые или неполные ячейки, способные принять выбранные в фильтре предметы.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «В инвентаре есть место» несколько раз разными цветами — по одному для каждого подключённого инвентаря.
Цвет триггера обозначает, с какой стороны трубы находится инвентарь, — так подключённые инвентари можно отличить друг от друга.
