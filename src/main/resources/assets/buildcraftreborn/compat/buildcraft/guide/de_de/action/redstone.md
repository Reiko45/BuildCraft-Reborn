<lore>
Wenn ausgelöst, wird ein Redstone-Signal ausgesendet.
</lore>
<no_lore>
„Redstone-Signal“ ist eine Gatteraktion, die jedes platzierte Gatter bietet.
</no_lore>

<chapter name="Voraussetzungen"/>
Wenn die Aktion aktiviert ist, sendet sie ein Redstone-Signal aus.

<chapter name="Parameter"/>
Wenn „Redstone-Signal“ gewählt ist und das verbaute Gatter Parameter unterstützt, steht „Nur auf Seite des Gatters“ als Parameter zur Verfügung.
Wählst du „Nur auf Seite des Gatters“, wird das Redstone-Signal nur an der Seite ausgesendet, auf der das Gatter sitzt.
