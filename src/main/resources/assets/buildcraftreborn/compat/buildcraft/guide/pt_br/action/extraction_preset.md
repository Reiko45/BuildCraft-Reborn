<lore>
O Tubo de Transporte de Emzuli oferece vários filtros de extração; você só precisa escolher um em uma porta lógica para que o tubo use esse filtro.
</lore>
<no_lore>
Extração Predefinida é uma ação de porta lógica disponível em qualquer porta lógica colocada em um Tubo de Transporte de Emzuli.
</no_lore>

<chapter name="Requisitos"/>
Quando a ação é ativada, a porta lógica permite que o Tubo de Emzuli extraia a cor da Extração Predefinida selecionada.
Se a porta lógica não definir nenhuma extração predefinida, o Tubo de Emzuli não conseguirá extrair nenhum item.
