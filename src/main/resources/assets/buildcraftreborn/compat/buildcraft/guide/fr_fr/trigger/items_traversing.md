<lore>
Quand des objets circulent dans le tuyau, le modificateur s'active.
</lore>
<no_lore>
« Objets en Transit » est un modificateur de porte disponible sur toute porte placée sur un tuyau de transport.
</no_lore>

<chapter name="Conditions"/>
Lorsqu'il est sélectionné, les actions connectées ne s'activent que si un objet circule dans le tuyau.

<chapter name="Paramètres"/>
Si vous utilisez « Objets en Transit » et que la porte installée dispose de paramètres, l'emplacement de filtre à côté devient disponible comme paramètre.
En plaçant un objet dans l'emplacement de filtre, vous pouvez vérifier si l'objet sélectionné circule dans le tuyau avant le déclenchement.
