<lore>
In welche Richtung soll das Rohr arbeiten oder transportieren? Nach unten? Dann wähle einfach diese Aktion.
</lore>
<no_lore>
„Zur Seite Unten ausrichten“ ist eine Gatteraktion, die jedes Gatter bietet, das auf einem Rohr sitzt, das zum Arbeiten eine festgelegte Richtung braucht und für das unten eine gültige Richtung ist.
</no_lore>

<chapter name="Richtung festlegen"/>
Wenn die Aktion aktiviert ist, legt das Rohr, auf dem das Gatter sitzt, die Unterseite als seine Richtung fest.
Das Rohr schickt seinen Inhalt dann nach unten bzw. führt seine Vorgänge in der Welt nach unten hin aus.
