<lore>
Laat de machine keer op keer draaien.
</lore>
<no_lore>
‘Lus’ is een poortactie die beschikbaar is op elke poort die naast een machine is geplaatst die kan werken.
</no_lore>

<chapter name="Vereisten"/>
Wanneer de actie is geactiveerd, doorloopt de machine haar werkcyclus steeds opnieuw.
Let op: niet alle machines ondersteunen de actie ‘Lus’.

<chapter name="Triggerrichtingen"/>
Poorten kunnen de actie ‘Lus’ meerdere keren in verschillende kleuren tonen, één voor elke aangesloten machine.
De kleur van de actie toont in welke richting de machine ten opzichte van de pijp ligt, zodat je de machines van elkaar kunt onderscheiden.
