# Простые одиночные теги
Каждый тег имеет вид &lt;name arguments/&gt;, где name — имя тега, а '/' в конце означает, что тег одиночный. У некоторых тегов также есть аргументы в виде «пар ключ-значение», например:
<guide_md>
"level"="42"
</guide_md>

## Новая страница
&lt;new_page/&gt; переносит всё, что идёт после него, на следующую страницу.

## Ссылки
Ссылка ведёт на другую страницу руководства и использует её заголовок и значок. Также можно сослаться на ItemStack или Statement, даже если для них нет страницы в руководстве.
Например:
<guide_md>
&lt;link to="buildcraftreborn:config/guide_entry_format"/&gt;
</guide_md>
даёт такой результат:
<link to="buildcraftreborn:config/guide_entry_format"/>

или:
<guide_md>
&lt;link to="minecraft:iron_ingot" type="item_stack"/&gt;
</guide_md>
даёт такой результат:
<link to="minecraft:iron_ingot" type="item_stack"/>

## Главы
&lt;chapter/&gt; создаёт «заголовок главы», который отображается в списке глав как цветной заголовок. У него есть один возможный аргумент — "level", целое число не меньше 0. Заголовки также можно создавать несколькими символами решётки (#), как в обычном markdown. Количество символов # минус один равно уровню заголовка.
Например:
<guide_md>
 ### Level 3 chapter
&lt;chapter name="Another level 3 chapter" level="2"/&gt;
</guide_md>
даёт такой результат:
### Глава уровня 3
<chapter name="Ещё одна глава уровня 3" level="2"/>

# Простые парные теги
Все эти теги должны обрамлять какое-то содержимое, и у каждого должен быть открывающий тег &lt;italic&gt; и закрывающий тег &lt;/italic&gt;
Они влияют на текст между открывающим и закрывающим тегами.

- <italic>курсив</italic> (italic)
- <bold>жирный</bold> (bold)
- <underline>подчёркнутый</underline> (underline)
- <strikethrough>зачёркнутый</strikethrough> (strikethrough)
- <red>красный</red> (red)
- <black>чёрный</black> (black)
- <dark_blue>тёмно-синий</dark_blue> (dark_blue)
- <dark_green>тёмно-зелёный</dark_green> (dark_green)
- <dark_aqua>тёмно-бирюзовый</dark_aqua> (dark_aqua)
- <dark_red>тёмно-красный</dark_red> (dark_red)
- <dark_purple>тёмно-фиолетовый</dark_purple> (dark_purple)
- <gold>золотой</gold> (gold)
- <gray>серый</gray> (gray)
- <dark_gray>тёмно-серый</dark_gray> (dark_gray)
- <blue>синий</blue> (blue)
- <green>зелёный</green> (green)
- <aqua>бирюзовый</aqua> (aqua)
- <light_purple>светло-фиолетовый</light_purple> (light_purple)
- <yellow>жёлтый</yellow> (yellow)
- <white>белый</white> (white)

Зелёный, бирюзовый, жёлтый и белый лучше не использовать: эти цвета обычно очень плохо видно на странице.

# Переключаемые теги
Все следующие теги зависят от настроек: игрок может включать и отключать их.

## Предыстория
Если флажок «Показывать предысторию [ ]» отмечен, скрывается всё, что находится в теге &lt;no_lore&gt;, иначе скрывается всё, что находится в теге &lt;lore&gt;.

Тег lore предназначен для «внутриигровой» информации, рассказанной от лица игрока (как будто он сам выясняет, как всё устроено). Противоположный тег служит для более формального, энциклопедического изложения — только факты, без прикрас.

В игре это включено по умолчанию, а при экспорте всегда отключено.

## Подсказки
Если флажок «Показывать подсказки [ ]» отмечен, скрывается всё, что находится в теге &lt;no_hint&gt;, иначе скрывается всё, что находится в теге &lt;hint&gt;.

Тег hint предназначен для дополнительных «подсказок» о том, для чего можно использовать описываемую вещь или как сочетать её с другими блоками и предметами. По сути, это «рекомендуемые способы применения» разных вещей. (Разбираться в этом самому — часть удовольствия, так что подсказки необязательны. Поэтому по умолчанию они отключены, но их можно включить в игре, а в будущем — и при экспорте.)

## Подробности
Если клиентский параметр конфигурации "guideBookEnableDetail" имеет значение "true", скрывается всё, что находится в теге &lt;no_detail&gt;, иначе скрывается всё, что находится в теге &lt;detail&gt;.

Тег detail предназначен для всех чисел, которые используются в расчётах: пропускной способности труб, скорости извлечения, частоты импульсов и т. д.

По умолчанию это отключено, но может переключаться в игре, а в будущем — и при экспорте.

# Разное
## Рецепт (один)
Этот тег показывает первый найденный рецепт для указанного предмета. Например:
<guide_md>
&lt;recipes stack="buildcraftreborn:gear_stone"&gt;
</guide_md>
<recipe stack="buildcraftreborn:gear_stone"/>

## Рецепты
Этот тег показывает все рецепты для указанного предмета. Например:
<guide_md>
&lt;recipes stack="buildcraftreborn:gear_wood"&gt;
</guide_md>
<recipes stack="buildcraftreborn:gear_wood" chapter_level="2"/>

## Применение
Аналогично рецептам, этот тег показывает все способы применения указанного предмета. Например:
<guide_md>
&lt;usages stack="buildcraftreborn:engine_wood"&gt;
</guide_md>
<usages stack="buildcraftreborn:engine_wood" chapter_level="2"/>

## Рецепты и применение
Этот тег, по сути, объединяет два предыдущих в один, например:
<guide_md>
&lt;recipes_usages stack="buildcraftreborn:pipe_structure"&gt;
</guide_md>
<recipes_usages stack="buildcraftreborn:pipe_structure" chapter_level="2"/>

## Группа
Показывает группы, подходящие для указанного предмета, statement и т. д.

## Изображения
Показывает изображение. У тега 3 аргумента:
* src: расположение исходного изображения.
* width: ширина, с которой будет показано изображение. По умолчанию — ширина исходного изображения (но это не всегда то, что нужно).
* height: высота, с которой будет показано изображение.

Например:
<guide_md>
&lt;image src="buildcraftreborn:item/wrench" width="64" height="64"/&gt;
</guide_md>
<image src="buildcraftreborn:item/wrench" width="64" height="64"/>
