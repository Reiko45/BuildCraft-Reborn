<chapter name="Reitin tekeminen"/>
Aseta Reittimerkkejä reitin varrelle enintään 64 palikan välein. Kun pidät Merkkiliitintä kädessäsi, himmeät laserit näyttävät, mitkä merkit voi yhdistää: katso yhtä niistä ja napsauta hiiren oikealla painikkeella yhdistääksesi kyseiset kaksi merkkiä. Yhdistä merkkejä lisää tehdäksesi pidemmän reitin.
<recipes_usages stack="buildcraftreborn:marker_path"/>
Napsauta Reittimerkkiä hiiren oikealla painikkeella kääntääksesi sen reitin suunnan: Rakentaja seuraa reittiä sen alusta loppuun.
<link to="buildcraftreborn:item/marker_connector"/>
<chapter name="Reitin käyttäminen"/>
Aseta Rakentaja reitin merkkiä vasten niin, että merkki on sen takana. Rakentaja ottaa reitin käyttöön, merkit putoavat tavaroina, ja se rakentaa pohjapiirrustuksensa tai kaavaimensa jokaisessa reitin vaiheessa eikä vain kerran.
