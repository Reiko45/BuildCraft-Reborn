<no_lore>
Линза — заглушка, которая окрашивает все проходящие через неё предметы в свой цвет.
</no_lore>

<recipes stack="buildcraftreborn:plug_lens"/>

<chapter name="Принцип работы"/>
Окраска предметов даёт дополнительные возможности фильтрации в системе труб, но их цвет в мире на самом деле не меняется.
Линзы можно ставить только на транспортные трубы для предметов, ведь окрашивать можно только предметы.

<chapter name="Соединения труб"/>
Заглушки можно ставить только на трубы, на любую их сторону.
Линза, поставленная между двумя трубами, не мешает соединению труб и проводов трубы.
