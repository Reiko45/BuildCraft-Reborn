<lore>
In welche Richtung soll das Rohr arbeiten oder transportieren? Nach Norden? Dann wähle einfach diese Aktion.
</lore>
<no_lore>
„Zur Seite Nord ausrichten“ ist eine Gatteraktion, die jedes Gatter bietet, das auf einem Rohr sitzt, das zum Arbeiten eine festgelegte Richtung braucht und für das Norden eine gültige Richtung ist.
</no_lore>

<chapter name="Richtung festlegen"/>
Wenn die Aktion aktiviert ist, legt das Rohr, auf dem das Gatter sitzt, Norden als seine Richtung fest.
Das Rohr schickt seinen Inhalt dann nach Norden bzw. führt seine Vorgänge in der Welt an seiner Nordseite aus.
