<chapter name="Käyttö"/>
Laita tyhjä Punakivipiirilevy vasemmassa yläkulmassa olevaan paikkaan. Kaikki ohjelmat, jotka piirilevylle voi asettaa, näytetään keskellä: valitse ohjelma napsauttamalla sitä (ja poista valinta napsauttamalla uudelleen). Laserit antavat sitten pöydälle energiaa, ja kun energiaa on kertynyt tarpeeksi, ohjelmoitu piirilevy ilmestyy vasemmassa alakulmassa olevaan paikkaan. Pöytä pitää ohjelman valittuna, joten se tekee saman piirilevyn uudelleen heti, kun ulostulopaikka on tyhjä.
