<lore>
С метками порой неудобно: чтобы изменить размер области, их приходится много раз ломать и ставить заново. Рамка объёма решает задачу проще: каждый её угол легко передвинуть.
</lore>
<no_lore>
Рамки объёма упрощают разметку: чтобы изменить их размер, не нужно ломать и ставить блоки.
</no_lore>
<chapter name="Информация"/>
Рамка объёма — это лазерная рамка, которой управляют с помощью разъема маркера.
<recipes_usages stack="buildcraftreborn:volume_box"/>
Щёлкните разъемом маркера по углу, который хотите передвинуть, и ведите курсор — размер рамки будет меняться вслед за ним.
Щёлкните ещё раз там, где угол должен остановиться. Чтобы полностью удалить рамку объёма, щёлкните по ней разъемом маркера с зажатым Shift.
