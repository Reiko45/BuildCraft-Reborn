<lore>
El cable de tubería conectado no brilla.
</lore>
<no_lore>
Tubo Señal OFF es un disparador de compuerta disponible en cualquier compuerta cuya tubería también tenga conectado un cable de tubería de ese color.
</no_lore>

<chapter name="Requisitos"/>
Cuando se selecciona, las acciones conectadas solo se activan si el cable de tubería conectado del mismo color no está activado.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Parámetros"/>
Si usas Tubo Señal OFF y la compuerta instalada tiene parámetros disponibles, las opciones Tubo Señal ON y Tubo Señal OFF de los demás colores de cable de tubería conectados pasan a estar disponibles como parámetro.
Seleccionar Tubo Señal ON o Tubo Señal OFF como parámetro de tu disparador inicial te permite exigir varias condiciones de cables de tubería antes de que se active.
