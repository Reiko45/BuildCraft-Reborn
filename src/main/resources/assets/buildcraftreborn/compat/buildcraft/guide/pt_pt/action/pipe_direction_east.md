<no_lore>
Apontar para o lado Leste é uma ação de gate disponível em qualquer gate colocado num tubo que precise de uma direção definida para funcionar, desde que o leste seja uma direção válida.
</no_lore>

<chapter name="Definir a direção"/>
Quando a ação é ativada, o tubo onde o gate está colocado define o leste como a sua direção.
Isto significa que o tubo envia o seu conteúdo para leste, ou realiza as suas operações no mundo do seu lado leste.
