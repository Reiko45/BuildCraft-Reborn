<lore>
Hat die Maschine daneben wirklich Arbeit, die sie erledigen könnte?
</lore>
<no_lore>
„Hat Arbeit“ ist ein Gatter-Trigger, den jedes Gatter bietet, das neben einer Maschine platziert ist, die arbeiten kann.
</no_lore>

<chapter name="Voraussetzungen"/>
Wenn er ausgewählt ist, werden die verbundenen Aktionen nur aktiviert, solange die angrenzende Maschine Arbeit hat, die sie erledigen könnte.

Hinweis: Nicht alle Maschinen unterstützen den Trigger „Hat Arbeit“.
