<chapter name="Создание пакетов"/>
Упаковщик рецептов делает пакеты из бумаги, а стол штамповки создаёт из них предметы. Во всплывающей подсказке показано содержимое пакета, разложенное как в сетке создания.
<chapter name="Метание"/>
Используйте пакет, чтобы бросить его. Раздатчики и активные трубы тоже умеют их бросать. При падении пакет разрывается и роняет своё содержимое, а всё, во что он попадает, получает небольшой урон за каждый предмет внутри.
