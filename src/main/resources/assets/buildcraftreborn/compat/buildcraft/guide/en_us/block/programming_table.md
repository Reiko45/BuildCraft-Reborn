<no_lore>
The Programming Table programs Redstone Boards using laser power.
</no_lore>
<chapter name="Use"/>
Put a blank Redstone Board in the top left slot. Every program the board can take is shown in the middle: click one to select it (and again to deselect it). Lasers then power the table, and when it has had enough power the programmed board appears in the bottom left slot. The table keeps the program selected, so it makes the same board again once the output slot is empty.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Pipes can put boards in and take programmed boards out.
