Marköranslutaren används för att ändra storleken på en volymlåda eller riktningen på en ansluten vägmarkör.
</no_lore>
<chapter name="Information"/>
För att använda marköranslutaren håller du den i handen, klickar på den laserlåda du vill justera och flyttar muspekaren för att justera den. Klicka sedan på den igen för att sluta justera.
Du kan skiftklicka på laserlådorna med marköranslutaren i handen för att ta bort laserlådan.
