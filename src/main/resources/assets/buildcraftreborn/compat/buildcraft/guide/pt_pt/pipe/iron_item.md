<no_lore>
O Tubo de Transporte de Ferro serve para transportar itens de um tubo numa só direção, para um tubo/inventário ligado.
</no_lore>

<chapter name="Funcionamento do tubo"/>
Os itens entram pelos lados opacos e saem pelo lado transparente.
Podes mudar a direção em que os itens seguem batendo com uma Chave Inglesa no lado do Tubo de Transporte de Ferro para onde queres que os itens vão, dando-lhe um sinal de redstone ou através de um gate.

Os itens não voltam para trás na direção de onde vieram; seguem apenas noutras direções.
Se os itens em trânsito não tiverem para onde ir, andam para trás e para a frente, a tentar continuamente seguir na direção definida.

Algumas máquinas conseguem enviar itens diretamente para este tubo, de forma automática, sem ser preciso passar por um tubo de extração alimentado.
Usar Plugues de Tubos ou pintar os tubos de cores diferentes pode impedir que os tubos se liguem.
