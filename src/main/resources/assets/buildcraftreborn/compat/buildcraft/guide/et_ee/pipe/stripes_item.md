<lore>
Kujuta ette toru, mis suudab plokke paigutada, lõhkuda ja kasutada. See ongi see toru, mida ette kujutad.
</lore>
<no_lore>
Triibulise transpordi toruga lõhutakse plokke, paigutatakse plokke ja kasutatakse sellest läbi juhitud esemeid ning transporditakse need ühendatud torusse või hoidlasse.
</no_lore>

<recipes stack="buildcraftreborn:pipe_stripes_item"/>

<chapter name="Toru töö"/>
Energia saamisel lõhub see otse enda ees oleva ploki ja annab selle edasi kõrvalolevale torule või hoidlale.
Kui sellest juhitakse läbi plokk, paigutab see ploki otse enda ette.
Kui sellest juhitakse läbi ese, püüab see seda „kasutada“ enda ees oleval plokil või olendil.

<chapter name="Toru suund"/>
Triibuline transpordi toru peab „osutama“ mingisse suunda, et mõjutada enda ees olevat plokki.
Kui sellega on ühendatud mitu toru või hoidlat, kaotab see võime maailma mõjutada.

<chapter name="Toru tööpõhimõte"/>
Kui liikuvatel esemetel pole kuhugi minna, kukuvad need torust maha.
Toru sulgejatega või torude eri värvi värvimisega saab takistada torude ühendumist.

<chapter name="Toide"/>
See võib saada energiat mis tahes MJ-energiaallikast, näiteks mootorist, Energiaadapterist või Toru pulsarist.
<link to="buildcraftreborn:block/engine_wood"/>
<link to="buildcraftreborn:item/plug_power_adaptor"/>
<link to="buildcraftreborn:item/plug_pulsar"/>
Iga saadud energiaimpulsiga kasutab see saadud energiat ja püüab enda ees oleva ploki lõhkuda.
Mida rohkem energiat impulsis on, seda rohkem energiat ploki lõhkumiseks kasutatakse.
