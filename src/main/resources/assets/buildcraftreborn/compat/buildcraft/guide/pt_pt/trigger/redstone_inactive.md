<lore>
O gate não está a receber nenhum sinal de redstone?
</lore>
<no_lore>
Sinal de Redstone Desligado é um gatilho de gate disponível em qualquer gate colocado.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações ligadas só são ativadas quando o bloco onde o gate está colocado não está a receber nenhum sinal de redstone.

<chapter name="Parâmetros"/>
Com Sinal de Redstone Desligado, se o gate instalado tiver parâmetros disponíveis, Gate Apenas Lateral fica disponível como parâmetro.
Selecionar Gate Apenas Lateral faz com que só seja verificado se o lado onde o gate está colocado não está a receber nenhum sinal de redstone.
