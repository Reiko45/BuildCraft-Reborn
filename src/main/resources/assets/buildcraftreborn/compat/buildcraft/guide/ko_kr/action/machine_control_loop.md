<lore>
기계를 몇 번이고 계속 돌려 봅시다.
</lore>
<no_lore>
반복은 작동할 수 있는 기계 옆에 설치된 모든 게이트에서 사용할 수 있는 게이트 액션입니다.
</no_lore>

<chapter name="요구 사항"/>
액션이 활성화되면 기계는 작동 주기를 계속해서 반복합니다.
참고: 모든 기계가 반복 액션을 지원하지는 않습니다.

<chapter name="트리거 방향"/>
게이트는 연결된 각 기계를 나타내기 위해 반복 액션을 여러 색으로 여러 번 표시할 수 있습니다.
액션의 색은 파이프를 기준으로 한 기계의 방향을 나타내므로 각 기계를 구분할 수 있습니다.
