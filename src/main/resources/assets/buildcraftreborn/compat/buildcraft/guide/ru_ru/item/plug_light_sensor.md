<lore>
Световой датчик позволяет управлять гейтами силой света.
</lore>
<no_lore>
Световой датчик — заглушка, которая определяет уровень освещённости блока перед собой и передаёт эти данные гейту на соседней стороне той же трубы.
</no_lore>

<recipes stack="buildcraftreborn:plug_light_sensor"/>

<chapter name="Принцип работы"/>
Благодаря этим данным соседний гейт с помощью триггеров «Ярко» и «Темно» может определять, светло вокруг или темно.
Триггеры «Ярко» и «Темно» можно использовать, чтобы запускать действия через гейт.

<link to="buildcraftreborn:trigger/light_low"/> 

<chapter name="Соединения труб"/>
Заглушки можно ставить только на трубы, на любую их сторону.
Датчик, поставленный между двумя трубами, блокирует любое соединение труб и проводов трубы.
