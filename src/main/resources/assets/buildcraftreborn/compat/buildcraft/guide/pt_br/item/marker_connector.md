<lore>
Um controle mais preciso das áreas em que suas máquinas trabalham é vital em qualquer projeto de engenharia de grande escala, e você precisa de uma ferramenta para isso.
</lore>
<no_lore>
O Conector de Marcadores serve para alterar o tamanho de uma caixa de volume ou a direção de um marcador de caminhos conectado.
</no_lore>
<chapter name="Informações"/>
Para usar o Conector de Marcadores, segure-o na mão, clique na caixa de laser que quer ajustar e mova o cursor para ajustá-la. Depois, clique de novo para parar de ajustá-la.
Com o conector de marcadores na mão, você pode usar Shift + clique em uma caixa de laser para removê-la.
