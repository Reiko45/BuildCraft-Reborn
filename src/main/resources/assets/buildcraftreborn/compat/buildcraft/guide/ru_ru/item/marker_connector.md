<chapter name="item.buildcraftreborn.marker_connector"/>
<lore>
В любом крупном инженерном проекте важно точно управлять областями, где работают ваши машины, — и для этого нужен инструмент.
</lore>
<no_lore>
Разъем маркера позволяет менять размер рамки объёма или направление соединённых направляющих меток.
</no_lore>
<chapter name="Информация"/>
Чтобы воспользоваться разъемом маркера, возьмите его в руку, щёлкните по лазерной рамке, которую хотите изменить, и двигайте курсор, чтобы её настроить. Затем щёлкните ещё раз, чтобы закончить.
Если держать разъем маркера в руке и щёлкнуть по лазерной рамке с зажатым Shift, рамка будет удалена.
