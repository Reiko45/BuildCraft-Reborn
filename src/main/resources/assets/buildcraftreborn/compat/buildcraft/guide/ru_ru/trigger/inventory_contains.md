<lore>
Есть ли в соседнем сундуке этот предмет?
</lore>
<no_lore>
«Инвентарь не пуст» — триггер, доступный в любом гейте, рядом с которым находится инвентарь.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в подключённом инвентаре есть предметы.

<chapter name="Параметры"/>
Если выбран триггер «Инвентарь не пуст» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны соседние ячейки фильтра.
Если положить предметы в ячейки фильтра, триггер сработает, только если в инвентаре есть хотя бы один из выбранных в фильтре предметов.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Инвентарь не пуст» несколько раз разными цветами — по одному для каждого подключённого инвентаря.
Цвет триггера обозначает, с какой стороны трубы находится инвентарь, — так подключённые инвентари можно отличить друг от друга.
