<lore>
Когда по трубе движутся предметы, триггер срабатывает.
</lore>
<no_lore>
«Перемещает предметы» — триггер, доступный в любом гейте, установленном на транспортную трубу.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда по трубе движется предмет.

<chapter name="Параметры"/>
Если выбран триггер «Перемещает предметы» и установленный гейт поддерживает параметры, в качестве параметра становится доступна соседняя ячейка фильтра.
Если положить предмет в ячейку фильтра, триггер сработает, только если по трубе движется выбранный в фильтре предмет.
