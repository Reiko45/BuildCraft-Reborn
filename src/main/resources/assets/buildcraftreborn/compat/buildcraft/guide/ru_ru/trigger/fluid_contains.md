<lore>
Есть ли в соседнем резервуаре хоть какая-то жидкость?
</lore>
<no_lore>
«Резервуар не пуст» — триггер, доступный в любом гейте, рядом с которым стоит резервуар.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в подключённом резервуаре есть жидкость.

<chapter name="Параметры"/>
Если выбран триггер «Резервуар не пуст» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны соседние ячейки фильтра.
Если положить в ячейки фильтра ёмкость с жидкостью, триггер сработает, только если в резервуаре есть выбранная в фильтре жидкость.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Резервуар не пуст» несколько раз разными цветами — по одному для каждого подключённого резервуара.
Цвет триггера обозначает, с какой стороны трубы находится резервуар, — так подключённые резервуары можно отличить друг от друга.
