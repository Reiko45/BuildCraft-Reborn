<chapter name="버튼"/>
다른 아이템의 기준이 될 아이템을 가장 왼쪽 슬롯에 넣고 원하는 버튼을 선택하기만 하면 됩니다.

필터링하려는 아이템의 모든 종류를 하나하나 모아 넣는 것은 지루할 수 있기 때문에, 리스트에는 여러 모드가 있습니다:
정확히 일치: 넣은 아이템과 같은 아이템입니다. 예: 손상 정도와 마법 부여가 같은 아이템.
유형: 같은 종류지만 다른 재료로 만든 아이템입니다. 예: 철 기어라면 나무 기어, 돌 기어 등 모든 종류의 기어와 일치합니다.
재료: 정확히 같은 재료로 만든 아이템입니다. 예: 철 기어라면 철 블록, 주괴, 광석, 조각처럼 철로 직접 만든 모든 것과 일치합니다.

아쉽게도 게임 내 모든 아이템이 지원되지는 않습니다.
