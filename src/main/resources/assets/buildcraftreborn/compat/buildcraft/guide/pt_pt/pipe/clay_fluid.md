<no_lore>
O Tubo de fluidos de argila serve para transportar fluidos de um tubo para tubos/tanques ligados.
</no_lore>

<chapter name="Funcionamento do tubo"/>
O Tubo de fluidos de argila dá prioridade à inserção de fluido num tanque adjacente antes de seguir para o tubo seguinte.
Os fluidos não voltam para trás na direção de onde vieram; seguem apenas noutras direções.
Se houver várias direções possíveis para o fluido, este é distribuído de forma igual entre elas (com prioridade para os tanques).

Algumas máquinas conseguem enviar fluidos diretamente para este tubo, sem ser preciso passar por um tubo de extração alimentado.
Usar Plugues de Tubos ou pintar os tubos de cores diferentes pode impedir que os tubos se liguem.

<no_detail>
O Tubo de fluidos de argila transporta fluidos para tubos e tanques adjacentes a 0,8 baldes por segundo.
Os tubos de fluidos têm um depósito interno que leva 1 balde por lado e 1 balde no centro.
</no_detail>
