<chapter name="item.buildcraftreborn.paintbrush"/>
<lore>
A quantidade de cores e salpicos que se encontra pelo mundo é impressionante, mas imagina poder mudar a cor de certos blocos do mundo com uma simples pincelada.
Pintar blocos para decoração é agradável, mas também pode ter uma utilidade prática, como separar tubos.
</lore>
<no_lore>
Os Pincéis podem ser usados para pintar vários blocos diferentes numa de 16 cores.
Pintar um bloco normalmente só serve para decoração, mas alguns blocos ganham propriedades especiais depois de pintados.
Por exemplo, os tubos não se ligam a outros tubos se estiverem pintados de cores diferentes.
</no_lore>
