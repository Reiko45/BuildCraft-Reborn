<no_lore>
Apontar para o lado Sul é uma ação de gate disponível em qualquer gate colocado num tubo que precise de uma direção definida para funcionar, desde que o sul seja uma direção válida.
</no_lore>

<chapter name="Definir a direção"/>
Quando a ação é ativada, o tubo onde o gate está colocado define o sul como a sua direção.
Isto significa que o tubo envia o seu conteúdo para sul, ou realiza as suas operações no mundo do seu lado sul.
