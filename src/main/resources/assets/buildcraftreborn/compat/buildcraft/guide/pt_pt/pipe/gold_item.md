<chapter name="Funcionamento do tubo"/>
O Tubo de Transporte de Ouro dá aos itens transportados um grande impulso de velocidade, para que circulem mais depressa pelos tubos.

Se tiver vários lados ligados, os itens seguem numa direção aleatória.
Os itens não voltam para trás na direção de onde vieram; seguem apenas noutras direções.
Se os itens em trânsito não tiverem para onde ir, saem do tubo e caem no chão.

Algumas máquinas conseguem enviar itens diretamente para este tubo, de forma automática, sem ser preciso passar por um tubo de extração alimentado.
Usar Plugues de Tubos ou pintar os tubos de cores diferentes pode impedir que os tubos se liguem.
