<no_lore>
レーザー刻印台は、レーザー動力でパッケージや単体のアイテムをクラフトするレーザー台です。
</no_lore>
<chapter name="使い方"/>
左のスロットにパッケージを入れ、レーザーを台に向けます。台はパッケージの中身をクラフトグリッドとしてクラフトし、中のアイテム1個につき40 MJを消費して、完成品を右のスロットに入れます。
それ以外のアイテムは、アイテム1個だけのレシピとして単独でクラフトされます。たとえば原木は40 MJで板材になります。
<recipes_usages stack="buildcraftreborn:stamping_table"/>
<chapter name="残ったもの"/>
クラフトできないものは、そのまま出力スロットに移動します。空のバケツなど、レシピで残るものは、まず3つの小さなスロットに、次に台の隣のインベントリに、最後は地面に置かれます。
<chapter name="自動化"/>
パイプを使えば、どの面からでもパッケージやアイテムを入れ、完成品や残ったものを取り出せます。
