Rörpulseraren är en användbar uppgradering jämfört med att driva trärör med motorer, men den känns... otillräcklig. Det vore praktiskt om det befintliga energinätet och motorerna kunde användas för att driva extraheringsrör i högre hastighet.
</lore>
<no_lore>
Energiadaptern är en anslutningsbar komponent som gör att rör som tar emot energi kan drivas via ett kinesisrör.
</no_lore>

<recipes stack="buildcraftreborn:plug_power_adaptor"/>

<chapter name="Komponentens funktion"/>
Den kan bara placeras på rör som tar emot energi, och alla kinesisrör som placeras bredvid den ansluter till den.

Energi som matas genom det anslutna kinesisröret kan driva det anslutna transport- eller vätskeröret som tar emot energi.

<chapter name="Röranslutningar"/>
Anslutningsbara komponenter kan bara placeras på rör, men de kan placeras på vilken sida av röret som helst.
Den stoppar alla andra rör- och rörkabelanslutningar mellan två rör när den placeras emellan, utom med kinesisrör och sig själv.
