<lore>
Une fois déclenchée, cette action émet un signal de redstone.
</lore>
<no_lore>
« Signal Redstone » est une action de porte disponible sur n'importe quelle porte posée.
</no_lore>

<chapter name="Conditions"/>
Lorsque l'action est activée, elle émet un signal de redstone.

<chapter name="Paramètres"/>
Si vous utilisez « Signal Redstone » et que la porte installée dispose de paramètres, « Porte latérale uniquement » devient disponible comme paramètre.
Choisir « Porte latérale uniquement » signifie que le signal de redstone n'est émis que par le côté précis sur lequel la porte est placée.
