<lore>
Quando há itens a passar pelo tubo, o gatilho é ativado.
</lore>
<no_lore>
Itens Passando é um gatilho de gate disponível em qualquer gate colocado num tubo de transporte.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações ligadas só são ativadas quando há um item a passar pelo tubo.

<chapter name="Parâmetros"/>
Com Itens Passando, se o gate instalado tiver parâmetros disponíveis, o espaço de filtro ao lado fica disponível como parâmetro.
Colocar um item nos espaços de filtro permite-te verificar, antes de acionar, se o item selecionado no espaço de filtro está a passar pelo tubo.
