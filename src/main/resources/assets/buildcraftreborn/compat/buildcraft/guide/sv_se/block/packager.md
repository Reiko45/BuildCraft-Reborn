<lore>
Ett recept, hopvikt och postat.
</lore>
<no_lore>
Receptpaketeraren packar ingredienserna i ett tillverkningsrecept i ett paket, redo att tillverkas av ett stämpelbord.
</no_lore>
<chapter name="Mönstret"/>
Rutnätet på 3x3 är receptets tillverkningsrutnät. Klicka på en plats med ett föremål för att platsen ska begära det föremålet. Klicka på en tom plats med tom hand för att den ska begära vad som helst (den lyser upp), och klicka igen för att stänga av det. Om du klickar med tom hand på en plats som begär ett föremål rensas den.
Alla platser som begär ”vad som helst” får samma föremål, ett som ingen annan plats begär med namn.
<recipes_usages stack="buildcraftreborn:packager"/>
<chapter name="Paketering"/>
Lägg papper i platsen längst upp till höger. Var fjärdedels sekund tar paketeraren ett föremål för varje upplyst plats, först från sina nio lagringsplatser och sedan från förråden på sina fyra sidor, och gör om ett papper till ett paket med varje föremål på sin plats. Paketet kommer ut i platsen under pappret, och paketeraren väntar tills det har tagits ut.
Ett paket kan läggas tillbaka i stället för papper för att fylla dess tomma platser: paketeraren lägger inget där paketet redan innehåller något.
<chapter name="Automatisering"/>
Rör matar in ingredienser i lagringsplatserna från sidorna (bara föremål som fyller på en befintlig stapel eller som mönstret kan använda), papper eller paket uppifrån eller nedifrån, och tar ut paket från alla sidor. Budbärarrobotar kan bära paketen till ett stämpelbord.
