<chapter name="Rohrverbindungen"/>
Er wird direkt an eine beliebige Seite eines Rohrs gesetzt, und kein Rohr, das auf dieser Seite daneben liegt, verbindet sich.

Rohraufsätze lassen sich nur auf Rohren platzieren, dafür aber an jeder Seite eines Rohrs.
