<lore>
Почему мои трубы всё время соединяются? Как это прекратить? Просто поставьте между ними заглушку для труб.
</lore>
<no_lore>
Заглушка для труб — устанавливаемая на трубу заглушка, которая не даёт трубам и/или проводам трубы соединяться друг с другом.
</no_lore>

<recipes stack="buildcraftreborn:plug_blocker"/>

<chapter name="Соединения труб"/>
Она ставится прямо на любую сторону трубы, и труба, поставленная рядом с этой стороны, не будет с ней соединяться.

Заглушки можно ставить только на трубы, на любую их сторону.
