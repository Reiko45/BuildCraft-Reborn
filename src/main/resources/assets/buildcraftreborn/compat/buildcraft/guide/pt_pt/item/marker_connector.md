<lore>
Um controlo mais preciso sobre as áreas onde as tuas máquinas trabalham é vital em qualquer projeto de engenharia de grande escala, e precisas de uma ferramenta para isso.
</lore>
<no_lore>
O Conector de marcadores serve para alterar o tamanho de uma caixa de volume ou a direção de um Marcador de Caminhos ligado.
</no_lore>
<chapter name="Informação"/>
Para usar o Conector de marcadores, segura-o na mão, clica na caixa laser que queres ajustar e move o cursor para a ajustar. Depois, clica novamente para parar de a ajustar.
Podes clicar com Shift nas caixas laser com o Conector de marcadores na mão para remover a caixa laser.
