<lore>
Подключённый провод трубы не светится.
</lore>
<no_lore>
«Сигнал выкл.» — триггер, доступный в любом гейте, если к той же трубе подключён провод трубы этого цвета.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда подключённый провод трубы того же цвета не включён.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Параметры"/>
Если выбран триггер «Сигнал выкл.» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны «Сигнал вкл.» и «Сигнал выкл.» для проводов трубы других подключённых цветов.
Если добавить «Сигнал вкл.» или «Сигнал выкл.» как параметр к исходному триггеру, для его срабатывания можно задать условия сразу для нескольких проводов трубы.
