<lore>
O tanque ao lado da porta lógica tem espaço para mais fluido?
</lore>
<no_lore>
Espaço para Fluído é um gatilho de porta lógica disponível em qualquer porta lógica que tenha um tanque ao lado.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações conectadas só são ativadas quando o tanque conectado tem espaço para receber mais fluido.

<chapter name="Parâmetros"/>
Ao usar Espaço para Fluído em uma porta lógica com parâmetros disponíveis, o espaço de Filtro ao lado dele fica disponível como parâmetro.
Colocar um recipiente de fluido no espaço de filtro permite verificar se há algum tanque que possa aceitar o fluido selecionado antes de acionar o gatilho.

<chapter name="Direções do gatilho"/>
As portas lógicas podem mostrar o gatilho Espaço para Fluído várias vezes, em cores diferentes, uma para cada tanque conectado.
A cor do gatilho indica a direção do tanque em relação ao tubo, para que você possa diferenciar cada um deles.
