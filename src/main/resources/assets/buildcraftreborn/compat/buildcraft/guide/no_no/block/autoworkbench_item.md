<chapter name="Informasjon"/>
Med Autoarbeidsbordet kan du lage gjenstander automatisk uten å gjøre det selv. Bare sett opp oppskriften på gjenstanden du vil lage, og send gjenstander inn i det gjennom rør.
<recipes_usages stack="buildcraftreborn:autoworkbench_item"/>
Send bare ressursene som oppskriften krever, inn i autoarbeidsbordet gjennom rør, så lager det sakte gjenstanden eller blokken – helt uten energi.
