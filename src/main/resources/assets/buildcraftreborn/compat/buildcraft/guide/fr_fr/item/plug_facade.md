<lore>
Vos tuyaux ne s'accordent pas avec le style de votre construction ? Placez simplement une façade du bloc assorti pour les cacher.
</lore>
<no_lore>
La Façade est un accessoire de tuyau qui sert à recouvrir vos tuyaux pour les assortir à votre construction.
</no_lore>

<recipes stack="buildcraftreborn:plug_facade"/>

<chapter name="Variantes de façades"/>
Presque tous les blocs du jeu peuvent être transformés en façade et placés sur le côté d'un tuyau.
Une Façade pleine bloque toute connexion entre les tuyaux si elle est placée entre eux.
Une Façade creuse laisse passer les connexions entre les tuyaux.
