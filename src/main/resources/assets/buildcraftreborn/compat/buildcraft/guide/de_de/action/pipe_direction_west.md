<lore>
In welche Richtung soll das Rohr arbeiten oder transportieren? Nach Westen? Dann wähle einfach diese Aktion.
</lore>
<no_lore>
„Zur Seite West ausrichten“ ist eine Gatteraktion, die jedes Gatter bietet, das auf einem Rohr sitzt, das zum Arbeiten eine festgelegte Richtung braucht und für das Westen eine gültige Richtung ist.
</no_lore>

<chapter name="Richtung festlegen"/>
Wenn die Aktion aktiviert ist, legt das Rohr, auf dem das Gatter sitzt, Westen als seine Richtung fest.
Das Rohr schickt seinen Inhalt dann nach Westen bzw. führt seine Vorgänge in der Welt an seiner Westseite aus.
