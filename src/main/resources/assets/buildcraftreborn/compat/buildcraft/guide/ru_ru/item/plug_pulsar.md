<lore>
Питать трубы бесплатно, без большого двигателя? Разве не здорово?
</lore>
<no_lore>
Труба-пульсар — заглушка, которая снабжает небольшим количеством энергии трубы, принимающие энергию.
</no_lore>

<recipes stack="buildcraftreborn:plug_pulsar"/>

<chapter name="Принцип работы"/>
Её можно ставить только на трубы, принимающие энергию; чтобы включить её, щёлкните по ней правой кнопкой мыши.
Включать трубу-пульсар можно и с помощью гейта, используя действия пульсара.

<link to="buildcraftreborn:action/pulsar_constant"/> 
<link to="buildcraftreborn:action/pulsar_single"/> 

<chapter name="Соединения труб"/>
Заглушки можно ставить только на трубы, на любую их сторону.
Труба-пульсар, поставленная между двумя трубами, блокирует любое соединение труб и проводов трубы.
