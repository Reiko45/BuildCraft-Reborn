Tout robot commence par une carte vierge.
</lore>
<no_lore>
La Table de programmation programme les Cartes de Redstone grâce à l'énergie laser.
</no_lore>
<chapter name="Utilisation"/>
Placez une Carte de Redstone vierge dans l'emplacement en haut à gauche. Tous les programmes que la carte peut recevoir s'affichent au milieu : cliquez sur l'un d'eux pour le sélectionner (et de nouveau pour le désélectionner). Les lasers alimentent alors la table, et lorsqu'elle a reçu assez d'énergie, la carte programmée apparaît dans l'emplacement en bas à gauche. La table garde le programme sélectionné : elle fabrique donc de nouveau la même carte dès que l'emplacement de sortie est vide.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Les tuyaux peuvent insérer des cartes et extraire les cartes programmées.
