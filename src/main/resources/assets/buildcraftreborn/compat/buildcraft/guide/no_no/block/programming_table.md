<no_lore>
Programmeringsbordet programmerer Redstonekretskort med laserenergi.
</no_lore>
<chapter name="Bruk"/>
Legg et tomt Redstonekretskort i plassen øverst til venstre. Alle programmene kortet kan få, vises i midten: Klikk på ett for å velge det (og igjen for å velge det bort). Lasere gir så bordet energi, og når det har fått nok energi, dukker det programmerte kortet opp i plassen nederst til venstre. Bordet beholder programmet valgt, så det lager det samme kortet igjen så snart utgangsplassen er tom.

Rør kan sette kretskort inn og ta programmerte kretskort ut.
