<lore>
Какого цвета двигатель рядом с гейтом? Зелёный?
</lore>
<no_lore>
«Двигатель зелёный» — триггер, доступный в любом гейте, рядом с которым находится двигатель.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда соседний двигатель находится на зелёной температурной стадии.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Двигатель зелёный» несколько раз разными цветами — по одному для каждого подключённого двигателя.
Цвет триггера обозначает, с какой стороны трубы находится двигатель, — так подключённые двигатели можно отличить друг от друга.
