<lore>
Неужели у соседней машины и правда есть работа?
</lore>
<no_lore>
«Есть работа» — триггер, доступный в любом гейте, установленном рядом с машиной, которая способна работать.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда у соседней машины есть работа.

Примечание: не все машины поддерживают триггер «Есть работа».
