<lore>
Todo robô começa como uma placa em branco.
</lore>
<no_lore>
A Mesa de Programação programa Placas de Redstone usando energia laser.
</no_lore>
<chapter name="Uso"/>
Coloque uma Placa de Redstone em branco no espaço do canto superior esquerdo. Todos os programas que a placa aceita aparecem no meio: clique em um para selecioná-lo (e de novo para desmarcá-lo). Os lasers então alimentam a mesa e, quando ela tiver recebido energia suficiente, a placa programada aparece no espaço do canto inferior esquerdo. A mesa mantém o programa selecionado, então produz a mesma placa de novo assim que o espaço de saída ficar vazio.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Os tubos podem inserir placas e retirar as placas programadas.
