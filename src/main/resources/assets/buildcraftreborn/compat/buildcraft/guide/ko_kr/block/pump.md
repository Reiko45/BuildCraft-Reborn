손으로 액체를 모으는 일은 꽤 지루하고 때로는 위험하기까지 해서, 액체를 자동으로 모을 방법이 필요해졌습니다.
</lore>
<no_lore>
펌프는 바로 아래에 있는 액체 원천과 그에 연결된 모든 원천을 자동으로 퍼 올리는 방법입니다.
</no_lore>

월드에서 액체를 모으려면 퍼 올리려는 액체의 원천 블록 위에 펌프를 설치하고 동력을 공급하세요.
아래에 있는 액체 원천은 가장 위의 원천부터 아래로 '빨아들여지며' 인접한 파이프/탱크로 자동 출력됩니다.
반경 64블록 범위에서 위에서 아래로, 연결된 액체의 바깥 가장자리에서 안쪽으로 액체를 퍼 올립니다.
<chapter name="기계 작동 방식"/>
대부분의 기계처럼 동력이 필요합니다. 동력을 많이 공급할수록 더 빨리 퍼 올립니다.
