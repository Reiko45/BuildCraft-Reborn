<lore>
¿Tiene espacio para más líquido el tanque que hay junto a la compuerta?
</lore>
<no_lore>
Espacio para Líquidos es un disparador de compuerta disponible en cualquier compuerta que tenga un tanque al lado.
</no_lore>

<chapter name="Requisitos"/>
Cuando se selecciona, las acciones conectadas solo se activan si el tanque conectado tiene espacio para recibir más líquido.

<chapter name="Parámetros"/>
Si usas Espacio para Líquidos y la compuerta instalada tiene parámetros disponibles, la ranura de Filtro que hay a su lado pasa a estar disponible como parámetro.
Si colocas un recipiente de líquido en la ranura de filtro, puedes comprobar si hay algún tanque que pueda aceptar el líquido seleccionado antes de que se active el disparador.

<chapter name="Direcciones del disparador"/>
Las compuertas pueden mostrar el disparador Espacio para Líquidos varias veces en distintos colores, uno por cada tanque conectado.
El color del disparador indica en qué dirección está el tanque respecto a la tubería, para que puedas distinguir cada tanque.
