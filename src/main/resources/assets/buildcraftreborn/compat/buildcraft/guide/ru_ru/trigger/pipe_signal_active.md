<lore>
Подключённый провод трубы ярко светится.
</lore>
<no_lore>
«Сигнал вкл.» — триггер, доступный в любом гейте, если к той же трубе подключён провод трубы этого цвета.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда подключённый провод трубы того же цвета включён.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Параметры"/>
Если выбран триггер «Сигнал вкл.» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны «Сигнал вкл.» и «Сигнал выкл.» для проводов трубы других подключённых цветов.
Если добавить «Сигнал вкл.» или «Сигнал выкл.» к исходному триггеру, для его срабатывания можно задать условия сразу для нескольких проводов трубы.
