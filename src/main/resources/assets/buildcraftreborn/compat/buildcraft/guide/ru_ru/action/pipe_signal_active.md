<lore>
Выберите это действие, чтобы подключённый провод трубы засветился.
</lore>
<no_lore>
«Сигнал вкл.» — действие, доступное в любом гейте, если к той же трубе подключён провод трубы этого цвета.
</no_lore>

<chapter name="Требования"/>
Когда действие активно, подключённый провод трубы того же цвета включается.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Параметр"/>
Если выбрано действие «Сигнал вкл.» и установленный гейт поддерживает параметры, в качестве параметров становятся доступны «Сигнал вкл.» и «Сигнал выкл.» для проводов трубы других подключённых цветов.
Если добавить «Сигнал вкл.» к исходному триггеру, при срабатывании исходных триггеров смогут включаться сразу несколько проводов трубы.
