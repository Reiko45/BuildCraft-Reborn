<lore>
Какого цвета двигатель рядом с гейтом? Чёрный, и он перегревается?
</lore>
<no_lore>
«Перегрев двигателя» — триггер, доступный в любом гейте, рядом с которым находится двигатель.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда соседний двигатель находится на стадии перегрева.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Перегрев двигателя» несколько раз разными цветами — по одному для каждого подключённого двигателя.
Цвет триггера обозначает, с какой стороны трубы находится двигатель, — так подключённые двигатели можно отличить друг от друга.
