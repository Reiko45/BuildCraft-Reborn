<no_lore>
«Инвентарь полон» — триггер, доступный в любом гейте, рядом с которым находится инвентарь.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в каждой ячейке подключённого инвентаря есть предмет.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Инвентарь полон» несколько раз разными цветами — по одному для каждого подключённого инвентаря.
Цвет триггера обозначает, с какой стороны трубы находится инвентарь, — так подключённые инвентари можно отличить друг от друга.
