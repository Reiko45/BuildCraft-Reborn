А вы знали, что трубу-пульсар можно заставить выдать всего один импульс?
</lore>
<no_lore>
«Одиночный энергетический пульс» — действие, доступное в любом гейте, если на той же трубе установлена труба-пульсар.
</no_lore>

<chapter name="Требования"/>
Когда действие активно, труба-пульсар ненадолго включается, и труба получает ровно столько энергии, сколько нужно для одной операции.

<link to="buildcraftreborn:item/plug_pulsar"/> 

<chapter name="Направления"/>
Гейт может показывать действие «Энергетический пульсар» несколько раз разными цветами — по одному для каждой подключённой трубы-пульсара.
Цвет действия обозначает, с какой стороны трубы находится труба-пульсар, — так их можно отличить друг от друга.
