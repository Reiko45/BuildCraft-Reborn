<lore>
Heeft de machine ernaast echt geen werk meer dat ze zou kunnen doen?
</lore>
<no_lore>
‘Werk klaar’ is een poorttrigger die beschikbaar is op elke poort die naast een machine is geplaatst die haar werk heeft voltooid.
</no_lore>

<chapter name="Vereisten"/>
Als deze trigger is gekozen, worden de verbonden acties alleen geactiveerd als de aangrenzende machine al het werk heeft voltooid dat ze kon doen.

Let op: niet alle machines ondersteunen de trigger ‘Werk klaar’.
