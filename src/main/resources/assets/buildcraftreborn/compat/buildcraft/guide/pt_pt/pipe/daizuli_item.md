<lore>
Queres separar os teus itens pintados? Basta definires uma cor e uma direção e enviá-los pelo tubo.
</lore>
<no_lore>
O Tubo de Transporte Daizuli serve para enviar os itens pintados que recebe numa só direção, para um tubo/inventário ligado.
</no_lore>

<chapter name="Funcionamento do tubo"/>
Os itens entram pelos lados opacos e saem pelo lado transparente.
Os itens não voltam para trás na direção de onde vieram; seguem apenas noutras direções.
Se os itens em trânsito não tiverem para onde ir, saem do tubo e caem no chão.

Algumas máquinas conseguem enviar itens diretamente para este tubo, de forma automática, sem ser preciso passar por um tubo de extração alimentado.
Usar Plugues de Tubos ou pintar os tubos de cores diferentes pode impedir que os tubos se liguem.

<chapter name="Definir a cor e a direção"/>
Podes mudar a direção para onde seguem os itens pintados batendo com uma Chave Inglesa no lado do tubo para onde queres que os itens vão, ou através de um gate.
Podes mudar a cor dos itens que seguem nessa direção batendo com uma Chave Inglesa no centro do tubo, ou através de um gate.
