<chapter name="item.buildcraftreborn.paintbrush"/>
<lore>
La cantidad de color que hay por todo el mundo es asombrosa, pero imagina poder cambiar el color de ciertos bloques con una simple pincelada.
Pintar bloques para decorar está bien, pero también puede tener un uso práctico, como separar tuberías.
</lore>
<no_lore>
Los pinceles sirven para pintar distintos bloques de uno de 16 colores.
Normalmente, pintar un bloque solo sirve para decorar, pero algunos bloques adquieren propiedades especiales al pintarlos.
Por ejemplo, las tuberías no se conectan con otras tuberías si están pintadas de colores distintos.
</no_lore>
