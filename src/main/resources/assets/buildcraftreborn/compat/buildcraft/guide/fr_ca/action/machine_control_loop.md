<lore>
Pour faire tourner la machine encore et encore.
</lore>
<no_lore>
« Boucle » est une action de porte disponible sur toute porte placée à côté d'une machine susceptible de fonctionner.
</no_lore>

<chapter name="Conditions"/>
Lorsque l'action est activée, la machine répète son cycle de fonctionnement sans arrêt.
Remarque : toutes les machines ne prennent pas en charge l'action « Boucle ».

<chapter name="Orientation des modificateurs"/>
Une porte peut afficher l'action « Boucle » plusieurs fois, dans des couleurs différentes, une pour chacune des machines connectées.
La couleur de l'action indique la direction de la machine par rapport au tuyau, ce qui vous permet de distinguer les machines entre elles.
