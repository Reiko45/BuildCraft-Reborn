<lore>
Para onde você quer que o tubo trabalhe ou transporte? Para o sul? É só selecionar esta ação.
</lore>
<no_lore>
Apontar para o Lado Sul é uma ação de porta lógica disponível em qualquer porta lógica colocada em um tubo que precise de uma direção definida para funcionar, desde que o sul seja uma direção válida.
</no_lore>

<chapter name="Definindo a direção"/>
Quando a ação é ativada, o tubo em que ela está colocada define o Sul como sua direção.
Isso significa que o tubo enviará seu conteúdo para o sul ou realizará suas operações no mundo pelo seu lado sul.
