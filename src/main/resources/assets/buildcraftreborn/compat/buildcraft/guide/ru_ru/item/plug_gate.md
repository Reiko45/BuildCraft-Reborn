</lore>

<chapter name="Установка гейта"/>
Гейт — заглушка, поэтому его можно ставить только на трубы, на любую их сторону.
Труба, поставленная рядом с этой стороны, не будет соединяться.

<chapter name="Уровни гейтов"/>
Гейты бывают разных уровней, и у каждого разное количество ячеек:
Основной гейт — 1 набор ячеек (его нельзя модифицировать).
Железный гейт — 2 набора ячеек.
Гейт из адского кирпича — 4 набора ячеек.
Золотой гейт — 8 наборов ячеек.

<chapter name="Модификаторы гейтов"/>
Гейты можно модифицировать, чтобы добавить ячейки параметров:
Лазуритовое расширение — по 1 ячейке параметра для каждого триггера.
Кварцевое расширение — по 1 ячейке параметра для каждого набора (вдвое сокращает количество ячеек гейта).
Алмазное расширение — по 3 ячейки параметров для каждого набора (вдвое сокращает количество ячеек гейта).

<chapter name="Варианты гейтов"/>
Гейт И активирует связь с действиями, только когда активны <bold>все</bold> подключённые триггеры.
Гейт ИЛИ активирует связь с действиями, когда активен <bold>хотя бы один</bold> подключённый триггер.

<chapter name="Триггеры"/>
Значки слева называются триггерами. Их перетаскивают в ячейки в левой части интерфейса.
Разные триггеры отслеживают разные вещи, и у каждого свои условия. Когда условие триггера выполняется, соседняя связь становится активной.

<chapter name="Действия"/>
Значки справа называются действиями. Их перетаскивают в ячейки в правой части интерфейса.
Разные действия выполняют разные задачи. Когда соседняя связь активна, подключённые к ней действия выполняются.

<chapter name="Параметры"/>
Если установлены ячейки параметров, рядом с некоторыми триггерами и действиями появляются дополнительные ячейки.
Эти дополнительные ячейки расширяют возможности и позволяют точнее настроить триггеры и действия.
В этих ячейках можно либо щёлкнуть по ячейке, чтобы открыть дополнительные настройки, либо положить в неё предметы в качестве фильтра.

<chapter name="Соединения"/>
Линии посередине соединяют триггеры с действиями, чтобы они работали вместе.
По ним можно щёлкать, чтобы соединять и разъединять их, — например, чтобы требовать срабатывания нескольких триггеров или запускать несколько действий.
Когда условие триггера выполнено, линия посередине загорается (лишь частично, если требуется несколько триггеров).
Когда линия горит, связанные с ней действия выполняются.
