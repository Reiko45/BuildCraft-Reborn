<lore>
Это выключит машину.
</lore>
<no_lore>
«Выкл.» — действие, доступное в любом гейте, установленном рядом с машиной, которая способна работать.
</no_lore>

<chapter name="Требования"/>
Когда действие активно, машина прекращает работу.
Примечание: не все машины поддерживают действие «Выкл.».

<chapter name="Направления триггера"/>
Гейт может показывать действие «Выкл.» несколько раз разными цветами — по одному для каждой подключённой машины.
Цвет действия обозначает, с какой стороны трубы находится машина, — так подключённые машины можно отличить друг от друга.
