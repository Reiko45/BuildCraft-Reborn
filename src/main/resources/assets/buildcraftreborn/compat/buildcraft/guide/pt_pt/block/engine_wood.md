<no_lore>
O Motor de Redstone é um motor básico que só precisa de um sinal de redstone para funcionar. Produz apenas uma quantidade ínfima de energia.
</no_lore>
<chapter name="Informação"/>
Devido à pouca quantidade de MJ que produzem, só servem para alimentar dispositivos simples, como tubos de extração ou bombas.
<recipes_usages stack="buildcraftreborn:engine_wood"/>


<chapter name="Funcionamento do motor"/>
Os motores do BuildCraft têm 5 fases de temperatura, que determinam a velocidade a que o motor trabalha: Azul, Verde, Amarelo, Vermelho e Preto.
Ao contrário dos motores mais potentes, os Motores de Redstone <bold>não sobreaquecem</bold> nem ficam pretos quando a energia não tem para onde ir: continuam simplesmente a trabalhar.
Os motores ligam-se sempre ao consumidor de MJ compatível mais próximo, mas os Motores de Redstone não se ligam a tubos cinéticos e só se ligam a certas máquinas.
Podes usar uma Chave Inglesa para o rodar e mudar o bloco que está a alimentar.

Como todos os motores, <bold>precisa de um sinal de redstone para funcionar.</bold>
Podes usar gates para detetar as fases de temperatura dos motores e assim controlá-los melhor.
