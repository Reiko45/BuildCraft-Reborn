<no_lore>
Programmeringsbänken programmerar redstonepaneler med laserkraft.
</no_lore>
<chapter name="Användning"/>
Lägg en tom redstonepanel i platsen längst upp till vänster. Alla program som panelen kan ta emot visas i mitten: klicka på ett för att välja det (och igen för att avmarkera det). Sedan driver lasrar bänken, och när den har fått tillräckligt med energi dyker den programmerade panelen upp i platsen längst ned till vänster. Bänken behåller det valda programmet, så den gör en likadan panel igen så snart utmatningsplatsen är tom.
