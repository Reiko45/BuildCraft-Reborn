<lore>
Selecciona esto para que el cable de tubería conectado se ilumine.
</lore>
<no_lore>
Tubo Señal ON es una acción de compuerta disponible en cualquier compuerta cuya tubería también tenga conectado un cable de tubería de ese color.
</no_lore>

<chapter name="Requisitos"/>
Cuando la acción se activa, se activa el cable de tubería conectado de ese mismo color.

<link to="buildcraftreborn:item/wire"/> 

<chapter name="Parámetro"/>
Si usas Tubo Señal ON y la compuerta instalada tiene parámetros disponibles, las opciones Tubo Señal ON y Tubo Señal OFF de los demás colores de cable de tubería conectados pasan a estar disponibles como parámetro.
Seleccionar Tubo Señal ON en tu disparador inicial te permite activar varios cables de tubería cuando se activan los disparadores iniciales.
