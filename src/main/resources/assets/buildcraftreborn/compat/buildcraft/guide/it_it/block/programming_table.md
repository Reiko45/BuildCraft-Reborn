<chapter name="Utilizzo"/>
Metti una Scheda di pietrarossa vuota nello slot in alto a sinistra. Al centro compaiono tutti i programmi che la scheda può ricevere: cliccane uno per selezionarlo (e di nuovo per deselezionarlo). I laser alimentano quindi il tavolo e, quando ha ricevuto abbastanza energia, la scheda programmata compare nello slot in basso a sinistra. Il tavolo mantiene il programma selezionato, quindi crea di nuovo la stessa scheda appena lo slot di uscita è vuoto.
