<lore>
Na tentativa de tirar o máximo partido dos teus combustíveis, usar fluidos frios já não chega: é preciso aquecer e arrefecer os fluidos até às suas várias temperaturas.

<chapter name="Informação"/>
O Permutador de calor serve para arrefecer ou aquecer fluidos e é composto por 3 partes: início, meio e fim, que se montam em conjunto para formar um multibloco.
Podes usar até 3 secções do meio para acelerar o processo.
