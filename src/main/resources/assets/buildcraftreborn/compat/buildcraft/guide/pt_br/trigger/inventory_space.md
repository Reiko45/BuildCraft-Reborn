<lore>
O baú ao lado tem espaço para mais itens?
</lore>
<no_lore>
Espaço no Inventário é um gatilho de porta lógica disponível em qualquer porta lógica que tenha um inventário ao lado.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações conectadas só são ativadas quando o inventário conectado tem espaços vazios para receber itens.

<chapter name="Parâmetros"/>
Ao usar Espaço no Inventário em uma porta lógica com parâmetros disponíveis, os espaços de Filtro ao lado dele ficam disponíveis como parâmetro.
Colocar itens nos espaços de filtro permite verificar se o inventário tem algum espaço vazio ou incompleto que possa aceitar os itens selecionados antes de acionar o gatilho.

<chapter name="Direções do gatilho"/>
As portas lógicas podem mostrar o gatilho Espaço no Inventário várias vezes, em cores diferentes, uma para cada inventário conectado.
A cor do gatilho indica a direção do inventário em relação ao tubo, para que você possa diferenciar cada um deles.
