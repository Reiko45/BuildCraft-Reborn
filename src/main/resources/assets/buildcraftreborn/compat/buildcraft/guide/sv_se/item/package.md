Ett paket innehåller ingredienserna i ett tillverkningsrecept, var och en på sin plats i tillverkningsrutnätet.
</no_lore>
<chapter name="Tillverka paket"/>
Receptpaketeraren gör paket av papper, och ett stämpelbord tillverkar dem. Inforutan visar vad ett paket innehåller, uppställt som dess tillverkningsrutnät.
<chapter name="Kasta"/>
Använd ett paket för att kasta det. Automater och transportrör av ränder kastar dem också. Där paketet landar spricker det upp och släpper det som det innehåller, och allt det träffar tar lite skada för varje föremål i det.
