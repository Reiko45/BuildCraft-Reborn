<chapter name="Rörets funktion"/>
Transportröret av kvarts ger transporterade föremål ett litet motstånd, så att accelererade föremål saktar in.

Transportrör av kvarts ansluter inte till transportrör av kullersten eller sten.

Om det har flera anslutna sidor färdas föremålen åt ett slumpmässigt håll.
Föremål färdas aldrig tillbaka åt det håll de kom ifrån, bara åt andra håll.
Om föremålen inte har någonstans att ta vägen släpps de ut ur röret på marken.

Vissa maskiner kan automatiskt mata ut föremål direkt i det utan att de behöver gå via ett drivet extraheringsrör.
Med rörpluggar, eller genom att måla rören i olika färger, kan du hindra rör från att ansluta.
