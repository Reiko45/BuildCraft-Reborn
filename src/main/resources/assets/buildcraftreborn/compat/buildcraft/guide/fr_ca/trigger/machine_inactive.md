<lore>
La machine voisine n'a-t-elle vraiment plus rien à faire ?
</lore>
<no_lore>
« Tâches finies » est un modificateur de porte disponible sur toute porte placée à côté d'une machine qui a terminé son travail.
</no_lore>

<chapter name="Conditions"/>
Lorsqu'il est sélectionné, les actions connectées ne s'activent que si la machine adjacente a terminé tout le travail qu'elle avait à faire.

Remarque : toutes les machines ne prennent pas en charge le modificateur « Tâches finies ».
