Para onde queres que o tubo trabalhe ou transporte? Para oeste? Basta selecionares esta ação.
</lore>
<no_lore>
Apontar para o lado Oeste é uma ação de gate disponível em qualquer gate colocado num tubo que precise de uma direção definida para funcionar, desde que o oeste seja uma direção válida.
</no_lore>

<chapter name="Definir a direção"/>
Quando a ação é ativada, o tubo onde o gate está colocado define o oeste como a sua direção.
Isto significa que o tubo envia o seu conteúdo para oeste, ou realiza as suas operações no mundo do seu lado oeste.
