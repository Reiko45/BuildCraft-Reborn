<lore>
Passen deine Rohre nicht zum Stil deines Bauwerks? Setz einfach eine passende Fassade aus einem Block darauf, um sie zu verstecken.
</lore>
<no_lore>
Eine Fassade ist ein Rohraufsatz, mit dem du deine Rohre passend zu deinem Bauwerk verkleidest.
</no_lore>

<recipes stack="buildcraftreborn:plug_facade"/>

<chapter name="Fassadenvarianten"/>
Fast jeder Block im Spiel lässt sich zu einer Fassade verarbeiten und an die Seite eines Rohrs setzen.
Eine massive Fassade unterbricht jede Rohrverbindung, wenn sie dazwischen sitzt.
Eine hohle Fassade lässt Rohrverbindungen durch sich hindurch zu.
