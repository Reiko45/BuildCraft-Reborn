<lore>
O Tubo de Transporte Emzuli oferece-te vários filtros de extração; só tens de escolher um num gate para que o tubo passe a usar esse filtro.
</lore>
<no_lore>
Extração Predefinida é uma ação de gate disponível em qualquer gate colocado num Tubo de Transporte Emzuli.
</no_lore>

<chapter name="Requisitos"/>
Quando a ação é ativada, o gate permite que o Tubo Emzuli extraia os itens da cor da Extração Predefinida selecionada.
Sem uma extração predefinida definida pelo gate, o Tubo Emzuli não consegue extrair nenhum item.
