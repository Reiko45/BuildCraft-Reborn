<chapter name="item.buildcraftreborn.marker_connector"/>
<lore>
Un control más preciso de las zonas en las que trabajan tus máquinas es vital en cualquier proyecto de ingeniería a gran escala, y necesitas una herramienta para ello.
</lore>
<no_lore>
El Conector de marcadores sirve para modificar el tamaño de una caja de volumen o la dirección de un marcador de ruta conectado.
</no_lore>
<chapter name="Información"/>
Para usar el Conector de marcadores, sostenlo en la mano, haz clic en la caja láser que quieras ajustar y mueve el cursor para ajustarla. Luego vuelve a hacer clic para dejar de ajustarla.
Con el conector de marcadores en la mano, puedes hacer Shift + clic en una caja láser para eliminarla.
