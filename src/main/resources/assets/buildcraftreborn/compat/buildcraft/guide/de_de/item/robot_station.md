<lore>
Jeder Roboter braucht einen Ort, an den er heimkehren kann.
</lore>
<no_lore>
Die Dockingstation ist ein Rohraufsatz, an dem Roboter platziert werden, andocken, schlafen und aufladen.
</no_lore>
<chapter name="Roboter platzieren"/>
Setze eine Dockingstation an die Seite eines Rohrs und klicke sie dann mit einem programmierten Roboter rechts an. Der Roboter ist nun mit dieser Station verbunden: Sie ist sein Zuhause.
<recipes_usages stack="buildcraftreborn:robot_station"/>
<chapter name="Lichter"/>
Die Lichter der Station zeigen, ob sie frei ist, von einem Roboter auf dem Weg reserviert wurde oder das Zuhause eines Roboters ist.
<chapter name="Gatter"/>
Ein Gatter auf demselben Rohr steuert die Station. Die Station kann Gegenstände oder Flüssigkeiten aus dem Block anbieten, aus dem das Rohr zieht (mit einem Holzrohr), Gegenstände oder Flüssigkeiten ins Rohr annehmen, Gegenstände anfordern, Roboter um das bitten, was die Maschine daneben braucht (ein Bestellblock), Robotern einen Arbeitsbereich zuweisen und Roboter verbieten oder erzwingen.
<chapter name="Energie"/>
Eine Station auf einer Energieleitung lädt den angedockten Roboter mit der Energie des Rohrs auf.
