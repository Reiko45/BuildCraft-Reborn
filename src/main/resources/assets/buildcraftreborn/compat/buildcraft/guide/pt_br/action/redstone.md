<lore>
Quando acionada, esta ação emite um sinal de redstone.
</lore>
<no_lore>
Sinal de Redstone é uma ação de porta lógica disponível em qualquer porta lógica colocada.
</no_lore>

<chapter name="Requisitos"/>
Quando a ação é ativada, a porta lógica emite um sinal de redstone.

<chapter name="Parâmetros"/>
Ao usar Sinal de Redstone em uma porta lógica com parâmetros disponíveis, a opção Apena Porta Lógica Lateral fica disponível como parâmetro.
Selecionar Apena Porta Lógica Lateral faz com que o sinal de redstone seja emitido apenas pelo lado em que a porta lógica está colocada.
