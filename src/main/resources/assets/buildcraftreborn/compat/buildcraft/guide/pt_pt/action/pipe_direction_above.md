<no_lore>
Apontar para o lado Cima é uma ação de gate disponível em qualquer gate colocado num tubo que precise de uma direção definida para funcionar, desde que o topo seja uma direção válida.
</no_lore>

<chapter name="Definir a direção"/>
Quando a ação é ativada, o tubo onde o gate está colocado define o topo como a sua direção.
Isto significa que o tubo envia o seu conteúdo para cima, ou realiza as suas operações no mundo para cima.
