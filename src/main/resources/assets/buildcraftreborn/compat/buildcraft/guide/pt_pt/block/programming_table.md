</no_lore>
<chapter name="Utilização"/>
Coloca uma Placa de Redstone em branco no espaço superior esquerdo. Todos os programas que a placa pode receber aparecem ao centro: clica num para o selecionar (e de novo para anular a seleção). Depois, os lasers alimentam a mesa e, quando esta tiver recebido energia suficiente, a placa programada aparece no espaço inferior esquerdo. A mesa mantém o programa selecionado, por isso volta a fazer a mesma placa assim que o espaço de saída ficar vazio.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Os tubos podem inserir placas e retirar as placas programadas.
