<chapter name="item.buildcraftreborn.paintbrush"/>
<lore>
A quantidade de cores espalhadas pelo mundo é impressionante, mas imagine poder mudar a cor de certos blocos com uma simples pincelada.
Pintar blocos para decorar é legal, mas também pode ter um uso prático, como separar tubos.
</lore>
<no_lore>
Os pincéis podem ser usados para pintar vários blocos diferentes com uma de 16 cores.
Normalmente, pintar um bloco só serve para decoração, mas alguns blocos ganham propriedades especiais depois de pintados.
Por exemplo, os tubos não se conectam a outros tubos se estiverem pintados de cores diferentes.
</no_lore>
