<lore>
По трубе, на которой стоит гейт, течёт жидкость.
</lore>
<no_lore>
«Перемещает жидкость» — триггер, доступный в любом гейте, установленном на жидкостную трубу.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда по трубе течёт жидкость.
