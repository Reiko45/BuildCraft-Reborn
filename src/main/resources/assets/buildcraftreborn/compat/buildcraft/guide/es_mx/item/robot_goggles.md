<chapter name="Batería"/>
El brillo de un robot indica cuánta carga tiene: rojo cuando la batería está vacía, amarillo cuando está a la mitad y verde cuando está llena. Un robot rojo pronto volverá a una Estación de acoplamiento situada en una tubería cinética para recargarse, o ya se ha detenido.
