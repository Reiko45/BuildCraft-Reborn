<lore>
Dans quelle direction le tuyau doit-il travailler ou transporter ? Vers le nord ? Choisissez simplement cette action.
</lore>
<no_lore>
« Orienter vers le côté Nord » est une action de porte disponible sur toute porte placée sur un tuyau qui a besoin d'une direction pour fonctionner, lorsque le nord est une direction valide.
</no_lore>

<chapter name="Définir la direction"/>
Lorsque l'action est activée, le tuyau sur lequel la porte est placée prend le nord comme direction.
Le tuyau envoie donc son contenu vers le nord, ou effectue ses opérations dans le monde de son côté nord.
