<lore>
Med Lazuli- og Daizuli-transportrør kan du farge gjenstander og sortere fargede gjenstander – denne handlingen bestemmer hvilken farge det farges eller sorteres etter.
</lore>
<no_lore>
Farg gjenstander er en porthandling som finnes på alle porter som er plassert på et Lazuli- eller Daizuli-transportrør.
</no_lore>

<chapter name="Krav"/>
Når handlingen er aktivert, stiller porten inn røret slik:
Lazuli-røret farger gjenstandene som passerer gjennom røret, i fargen som er valgt med handlingen Farg gjenstander.
Daizuli-røret sender bare gjenstander som er farget i fargen som er valgt med handlingen Farg gjenstander, i den valgte retningen.
