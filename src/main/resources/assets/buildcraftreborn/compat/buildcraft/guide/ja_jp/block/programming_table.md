<lore>
どんなロボットも、始まりは白紙のボード1枚から。
</lore>
<no_lore>
レーザープログラム台は、レーザー動力を使ってレッドストーンボードにプログラムを書き込みます。
</no_lore>
<chapter name="使い方"/>
左上のスロットに白紙のレッドストーンボードを入れます。ボードに書き込めるプログラムがすべて中央に表示されるので、1つクリックして選択します（もう一度クリックすると選択解除）。あとはレーザーで台に動力を供給し、十分な動力がたまると、プログラム済みのボードが左下のスロットに現れます。プログラムは選択されたままなので、出力スロットが空になると、同じボードをまた作ります。
<recipes_usages stack="buildcraftreborn:programming_table"/>
パイプでボードを入れたり、プログラム済みのボードを取り出したりできます。
