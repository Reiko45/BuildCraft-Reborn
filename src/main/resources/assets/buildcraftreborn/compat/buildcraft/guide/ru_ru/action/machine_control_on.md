<lore>
Это включит машину.
</lore>
<no_lore>
«Вкл.» — действие, доступное в любом гейте, установленном рядом с машиной, которая способна работать.
</no_lore>

<chapter name="Требования"/>
Когда действие активно, машина начинает работать.
Примечание: не все машины поддерживают действие «Вкл.».

<chapter name="Направления триггера"/>
Гейт может показывать действие «Вкл.» несколько раз разными цветами — по одному для каждой подключённой машины.
Цвет действия обозначает, с какой стороны трубы находится машина, — так подключённые машины можно отличить друг от друга.
