<lore>
A porta lógica está recebendo um sinal de redstone?
</lore>
<no_lore>
Sinal de Redstone Ligado é um gatilho de porta lógica disponível em qualquer porta lógica colocada.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações conectadas só são ativadas quando o bloco em que a porta lógica está colocada está recebendo um sinal de redstone.

<chapter name="Parâmetros"/>
Ao usar Sinal de Redstone Ligado em uma porta lógica com parâmetros disponíveis, a opção Apena Porta Lógica Lateral fica disponível como parâmetro.
Selecionar Apena Porta Lógica Lateral faz com que seja verificado apenas se o lado em que a porta lógica está colocada está recebendo um sinal de redstone.
