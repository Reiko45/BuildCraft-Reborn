Každý robot začína ako prázdna tabuľa.
</lore>
<no_lore>
Programovací stôl programuje Ruditové tabule pomocou laserovej energie.
</no_lore>
<chapter name="Použitie"/>
Vložte prázdnu Ruditovú tabuľu do slotu vľavo hore. Uprostred sa zobrazia všetky programy, ktoré tabuľa dokáže prijať: kliknutím jeden vyberiete (ďalším kliknutím výber zrušíte). Stôl potom napájajú lasery, a keď dostane dosť energie, naprogramovaná tabuľa sa objaví v slote vľavo dole. Stôl si zvolený program pamätá, takže keď sa výstupný slot uvoľní, vyrobí rovnakú tabuľu znova.
<recipes_usages stack="buildcraftreborn:programming_table"/>
Rúry môžu tabule vkladať a naprogramované tabule vyberať.
