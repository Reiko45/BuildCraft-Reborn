<lore>
Пусть машина работает снова и снова.
</lore>
<no_lore>
«Цикл» — действие, доступное в любом гейте, установленном рядом с машиной, которая способна работать.
</no_lore>

<chapter name="Требования"/>
Когда действие активно, машина раз за разом повторяет свой рабочий цикл.
Примечание: не все машины поддерживают действие «Цикл».

<chapter name="Направления триггера"/>
Гейт может показывать действие «Цикл» несколько раз разными цветами — по одному для каждой подключённой машины.
Цвет действия обозначает, с какой стороны трубы находится машина, — так подключённые машины можно отличить друг от друга.
