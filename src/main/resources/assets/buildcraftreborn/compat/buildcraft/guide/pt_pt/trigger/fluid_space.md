<lore>
O tanque ao lado do gate tem espaço para mais fluido?
</lore>
<no_lore>
Espaço para Fluidos é um gatilho de gate disponível em qualquer gate que tenha um tanque colocado ao lado.
</no_lore>

<chapter name="Requisitos"/>
Quando selecionado, as ações ligadas só são ativadas quando o tanque ligado tem espaço para receber mais fluido.

<chapter name="Parâmetros"/>
Com Espaço para Fluidos, se o gate instalado tiver parâmetros disponíveis, o espaço de filtro ao lado fica disponível como parâmetro.
Colocar um recipiente de fluido no espaço de filtro permite-te verificar, antes de acionar, se há algum tanque que possa aceitar o fluido selecionado no filtro.

<chapter name="Direções do gatilho"/>
Os gates podem mostrar o gatilho Espaço para Fluidos várias vezes, em cores diferentes, para representar cada um dos tanques ligados.
A cor do gatilho representa a direção do tanque em relação ao tubo, para que possas distinguir cada tanque.
