<lore>
每台機器人都是從一塊空白的紅石板開始的。
</lore>
<no_lore>
程式設計工作檯使用雷射能量為紅石板寫入程式。
</no_lore>
<chapter name="使用方式"/>
將空白紅石板放入左上角的欄位。紅石板可寫入的所有程式都會顯示在中間：點擊其中一個即可選取（再點一次取消選取）。接著以雷射為工作檯供能，累積足夠的能量後，寫好程式的紅石板就會出現在左下角的欄位。工作檯會保留所選的程式，所以只要輸出欄位清空，它就會再製作一塊相同的紅石板。
<recipes_usages stack="buildcraftreborn:programming_table"/>
導管可以送入紅石板，也可以取出已寫入程式的紅石板。
