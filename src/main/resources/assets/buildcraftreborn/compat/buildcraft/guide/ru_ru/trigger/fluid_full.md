<lore>
Полон ли резервуар рядом с гейтом?
</lore>
<no_lore>
«Резервуар полон» — триггер, доступный в любом гейте, рядом с которым стоит резервуар.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в соседнем резервуаре больше нет места для жидкости.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «Резервуар полон» несколько раз разными цветами — по одному для каждого подключённого резервуара.
Цвет триггера обозначает, с какой стороны трубы находится резервуар, — так подключённые резервуары можно отличить друг от друга.
