<lore>
Есть ли в резервуаре рядом с гейтом место для жидкости?
</lore>
<no_lore>
«В резервуаре есть место» — триггер, доступный в любом гейте, рядом с которым стоит резервуар.
</no_lore>

<chapter name="Требования"/>
Если выбран этот триггер, подключённые действия активируются, только когда в подключённом резервуаре есть место для жидкости.

<chapter name="Параметры"/>
Если выбран триггер «В резервуаре есть место» и установленный гейт поддерживает параметры, в качестве параметра становится доступна соседняя ячейка фильтра.
Если положить в ячейку фильтра ёмкость с жидкостью, триггер сработает, только если найдётся резервуар, способный принять выбранную в фильтре жидкость.

<chapter name="Направления триггера"/>
Гейт может показывать триггер «В резервуаре есть место» несколько раз разными цветами — по одному для каждого подключённого резервуара.
Цвет триггера обозначает, с какой стороны трубы находится резервуар, — так подключённые резервуары можно отличить друг от друга.
