<lore>
In welche Richtung soll das Rohr arbeiten oder transportieren? Nach oben? Dann wähle einfach diese Aktion.
</lore>
<no_lore>
„Zur Seite Oben ausrichten“ ist eine Gatteraktion, die jedes Gatter bietet, das auf einem Rohr sitzt, das zum Arbeiten eine festgelegte Richtung braucht und für das oben eine gültige Richtung ist.
</no_lore>

<chapter name="Richtung festlegen"/>
Wenn die Aktion aktiviert ist, legt das Rohr, auf dem das Gatter sitzt, die Oberseite als seine Richtung fest.
Das Rohr schickt seinen Inhalt dann nach oben bzw. führt seine Vorgänge in der Welt nach oben hin aus.
